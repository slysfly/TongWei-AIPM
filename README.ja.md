## 概要

通維 AI-PM は、プロジェクトマネジメント（PMI 中国フレームワーク）向けの AI 支援プラットフォームです。エージェント・ワークフロー、ナレッジベース検索とドキュメントプレビュー、構造化 ITTO 機能、事例ベースの指導とトレーニング体系を統合し、プロジェクトマネージャーとチームの生産性向上を AI で支援します。

## 主な機能

- **エージェント体系**：85 の領域/知識ユニット・エージェントを内蔵。統一された 6 項目スキーマで、手動・自動実行に対応。
- **ナレッジベース（KB）**：PDF/Word/Excel/画像/テキストなど複数形式の文書を解析・ベクトル化し、オンラインでプレビュー。
- **構造化 ITTO**：プロジェクトマネジメントの ITTO（インプット/ツールと技法/アウトプット）を構造化データに変換し、エージェントから呼び出し可能に。
- **事例指導 / トレーニング**：PMI 認定および実務向けのコンテンツ。
- **PWA オフライン**：Service Worker キャッシュによるオフラインアクセスとインストール可能な PWA。
- **多言語 UI**：組み込みの i18n により中国語/英語などを切り替え。
- **管理コンソール**：ユーザー、権限、ナレッジベース、実行監視。

## 技術スタック

- **フロントエンド**: React + TypeScript + Vite + Ant Design
- **バックエンド**: FastAPI + PostgreSQL + pgvector（ベクトル検索）
- **デプロイ**: Nginx リバースプロキシ、systemd サービス（ai-pm.service）、PWA

## デプロイと実行

フロントエンド構築：

```bash
cd frontend && npm install && npm run build
```

バックエンド起動：

```bash
cd backend && pip install -r requirements.txt && uvicorn serve:app --host 0.0.0.0 --port 8000
```

より詳しいデプロイ・運用・インストール手順は、リポジトリ内の `DEPLOYMENT.md`、`操作手册.md`、`管理员运维手册.md` を参照してください。
