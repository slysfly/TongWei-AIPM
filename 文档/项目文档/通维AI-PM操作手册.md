## 第 1 章 系统概述

### 1.1 产品定位

通维 AI-PM 是一套以 **通维咨询 标准** 为方法论底座、以 **AI 原生多智能体** 为引擎的项目管理平台。它覆盖项目从启动、计划、执行、监控到收尾的 **全生命周期管理**，并内置 11 个主流大模型（LLM）Provider，可在不依赖外部付费 Key 的情况下开箱即用基础 AI 能力。

### 1.2 核心能力一览

| 能力域 | 包含模块 | 说明 |
|--------|----------|------|
| 项目与任务 | 仪表盘、项目、任务、看板、项目组合 | 项目全生命周期 CRUD + 多视图 |
| 计划与进度 | OKR、日历、Sprint、路线图 | 目标、排期、迭代、路线图一体化 |
| 监控与评价 | 报表、EVM 挣值、风险登记册、变更控制、资源管理 | 量化监控与合规控制 |
| 审批与合规 | 审批流、合规管理 | 多级审批 + 合规策略 |
| AI 能力 | AI 智能体、多智能体编排、AI WBS、知识库(RAG)、AI 辅助填写 | 11 个 LLM + Agent 编排 |
| 自动化与集成 | 自动化规则、Webhook、飞书/钉钉/企业微信/Slack/GitHub/Google/Zoom、OpenClaw | 双向同步 + 事件触发 |
| 协作与文档 | 文档、白板、通知、经验教训 | 团队协同与知识沉淀 |
| 系统配置 | 设置、方法论模板、MCP 协议 | 平台级配置与扩展 |

### 1.3 默认访问地址

- 前端页面与后端 API **同源托管在 8000 端口**（已修复为相对 `/api`，从本机或局域网 IP 访问均自动命中 8000）。
- 本机访问：`http://localhost:8000`
- 局域网访问（同网段其他电脑）：`http://<本机IP>:8000`

## 第 2 章 部署与启动（开箱即用）

### 2.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10+ / Linux（主流发行版） / macOS |
| Python | **3.11 及以上**（安装时勾选 "Add to PATH"） |
| 网络 | 首次启动需联网安装 Python 依赖（约 2–5 分钟） |
| 数据库 | 内置 SQLite，**无需** 额外安装；生产可切换 PostgreSQL |
| 中间件 | 内置内存版 Redis/Celery，**无需** 安装 Redis |

> 目标机器若已装有 **OpenClaw**，本系统可自动把大模型配置同步给 OpenClaw，未安装也不影响独立运行。

### 2.2 安装步骤

1. 将 `AI-PM-Installer.zip` 拷贝到目标机器，解压到任意目录（如 `D:\AI-PM`）。
2. 解压后的目录结构：

```
AI-PM-Installer/
├── 启动.bat          # Windows 一键启动
├── 启动.ps1          # Windows PowerShell 启动
├── start.sh          # Linux / macOS 启动
├── ai-pm.service     # Linux systemd 常驻服务样例
├── README-安装包.md   # 安装包说明
├── backend/          # 后端（含开箱即用 .env）
└── frontend/dist/    # 已构建前端
```

### 2.3 启动系统

**Windows：**
- 双击 `启动.bat`。
- 首次运行会自动依次执行：创建 Python 虚拟环境 → 安装依赖 → 初始化数据库并创建管理员 → 启动服务 → 自动打开浏览器。
- 过程中可能弹出"Windows 已保护你的电脑"提示，点击"更多信息 → 仍要运行"即可。

**Linux / macOS：**
```bash
cd AI-PM-Installer
bash start.sh
```

**作为常驻服务（Linux 服务器）：**
```bash
# 参考 ai-pm.service 样例，复制到 /etc/systemd/system/ 后：
sudo systemctl daemon-reload
sudo systemctl enable --now ai-pm
```

### 2.4 验证启动成功

- 浏览器自动打开 `http://localhost:8000` 并出现登录页即成功。
- 若未自动打开，手动访问；若提示无法连接，请确认 8000 端口未被占用，并查看 `backend/logs/` 下的日志。

### 2.5 默认管理员账号

| 字段 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | `admin123` |

> ⚠️ 出于安全，**首次登录后请立即在「设置 → 用户管理」中修改 admin 密码**（系统已启用 90 天强制更换、弱密码检测策略）。

## 第 3 章 登录与账户管理

### 3.1 登录

1. 打开 `http://localhost:8000`，进入登录页。
2. 填写：
   - **用户名**：`admin`
   - **密码**：`admin123`
3. 点击「登录系统」按钮。
4. 登录成功自动跳转至仪表盘（`/`）。

> 登录页左侧品牌区展示了系统关键指标：11 个 AI Provider、72 张数据表、56 个路由模块 / ~400 API 端点。

### 3.2 退出登录

- 点击左侧导航栏底部的用户头像 / 用户名区域，选择「退出登录」即可返回登录页。

### 3.3 修改密码与账户安全

- 进入「设置 → 用户管理 / 安全设置」：
  - 可修改当前用户密码。
  - 系统强制密码策略：**至少 12 位，含大写、小写、数字、特殊字符**，并检测常见弱密码。
  - 密码 **90 天** 强制更换；到期后会提示重置。

## 第 4 章 界面总览

### 4.1 整体布局

系统采用经典的「**左侧导航栏 + 右侧内容区**」布局：

- **左侧导航栏（Sider）**：含顶部 Logo、分组菜单（项目、敏捷、计划、监控、AI、集成、系统）。菜单项较多时会**自动出现独立滚动条**，顶部 Logo 固定，可滚动查看全部菜单（含底部「设置」）。
- **右侧内容区**：按路由展示对应页面，内容区自身独立滚动。
- **顶部**：部分页面含页面标题、搜索框、筛选器与「新建」按钮。

### 4.2 导航栏分组说明

导航栏按业务域分组，主要入口如下（名称已按最新版更新）：

| 分组 | 菜单项 | 路由 |
|------|--------|------|
| 工作区 | 仪表盘 | `/` |
| 项目 | 项目列表、任务、看板、项目组合 | `/projects`、`/tasks`、`/kanban`、`/portfolio` |
| 敏捷 | OKR、Sprint、路线图 | `/okrs`、`/sprints`、`/roadmap` |
| 计划 | 日历 | `/calendar` |
| 监控 | 报表、EVM、风险登记册、变更控制、资源管理 | `/reports`、`/evm`、`/risk`、`/changes`、`/resources` |
| 审批 | 审批流 | `/approvals` |
| AI | AI 智能体、多智能体编排、AI WBS、知识库 | `/agents`、`/orchestration`、`/ai/wbs`、`/knowledge` |
| 自动化 | 自动化规则、Webhook、集成 | `/automations`、`/webhooks`、`/integrations` |
| 协作 | 文档、白板、通知、经验教训 | `/documents`、`/whiteboard`、`/notifications`、`/lessons` |
| 系统 | 方法论模板、MCP、设置 | `/methodology`、`/mcp`、`/settings` |

> 原「通维咨询 体系」分组已更名为 **「管控体系」**。

### 4.3 快捷操作区

- 仪表盘底部提供「🚀 快捷操作」卡片，一键盘跳转：新建项目、创建任务、AI 智能体、项目组合、OKR、生成报表、风险登记册、变更控制、自动化规则、经验教训、查看集成、看板视图。

### 4.4 通用交互约定

- 列表页通常支持 **搜索框（关键词）、状态下拉筛选、优先级筛选**。
- 表单页的「名称/标题」多为必填项，标有红色星号。
- 带 **AI 图标（机器人）的按钮** 为「AI 辅助填写」，可在表单中由 AI 自动补全内容。
- 删除操作一般会二次确认（弹窗或气泡确认）。

## 第 5 章 核心项目管理

### 5.1 仪表盘（`/`）

登录后首屏，提供全局概览：

1. **欢迎横幅**：显示当前日期，并提示"今日有 N 个逾期任务需要关注"；右侧「新建项目」按钮直达项目页。
2. **KPI 统计卡片**（4 张）：
   - 项目总数、进行中项目、任务总数、已完成任务（含完成率）。
3. **项目进度概览**（左）：展示最近 5 个项目，含状态标签与进度条；点击卡片进入项目详情。
4. **最近项目**（右）：列表展示最近项目，点击「打开」进入详情；右上「查看全部」跳项目列表。
5. **快捷操作**（底部）：见 4.3。

> 若系统为空（无项目），仪表盘会显示「暂无项目」空状态并引导创建。

### 5.2 项目列表（`/projects`）

**查看与筛选：**
- 顶部搜索框输入关键字（项目名 / 描述）实时过滤。
- 「状态筛选」：全部 / 进行中 / 规划 / 已完成 / 已归档。
- 「优先级」：全部 / 高(1) / 中(3) / 低(5)。
- 卡片网格展示，每张卡片显示：名称、状态标签、优先级标签、方法论标签（瀑布/Scrum/Kanban/SAFe/混合）、描述、进度条、起止日期。

**新建项目：**
1. 点击右上「新建项目」。
2. 填写表单：
   - **项目名称**（必填）：如"智慧城市管理系统"。
   - **描述**：项目概述。
   - **状态**：规划 / 进行中 / 已完成 / 已归档（默认"规划"）。
   - **优先级**：高 / 中 / 低（默认"中"）。
   - **方法论**：瀑布 / Scrum / Kanban / SAFe / 混合。
   - **行业**：如 IT软件 / 金融 / 制造 / 建筑。
   - **预算**：金额（¥）。
   - **开始日期 / 结束日期**：日期选择器。
3. （可选）点击表单中的 **AI 辅助填写** 按钮，由 AI 根据已有信息补全描述、行业等字段。
4. 点击「创建项目」。

**编辑 / 删除：**
- 卡片右下角图标：✏️ 编辑（弹窗修改）、🗑️ 删除（确认后删除）。
- 点击卡片主体进入 **项目详情页**（`/projects/:id`）。

**项目详情页：**
- 展示项目基本信息、进度、关联任务、文档、成员等（具体卡片依页面实现）。
- 可在详情页继续管理该项目下的任务、看板、文档等。

### 5.3 任务管理（`/tasks`）

**全局任务视图：**
- 顶部统计卡片：总任务、已完成、逾期、完成率。
- 表格列：WBS 编码、任务、状态、优先级、负责人、进度、截止、操作。

**筛选与搜索：**
- 搜索框：按任务名或 WBS 编码过滤。
- 「按项目筛选」：选择某项目只看其任务。
- 「看板视图」按钮：跳转到 `/kanban`。

**新建任务：**
1. 点击「新建任务」。
2. 表单字段：
   - **所属项目**（必填）：下拉选择。
   - **任务名称**（必填）。
   - **描述**：任务说明。
   - **状态**：待办 / 待开始 / 进行中 / 评审中 / 测试中 / 已完成 / 已取消。
   - **优先级**：1–5 数字（数字越大优先级越低，4–5 标红）。
   - **负责人 ID**：填写用户标识，如 `u_1001`。
   - **计划开始 / 计划结束**：日期。
   - **预估工时(h)**：数字。
3. 同样可使用 **AI 辅助填写** 自动完善任务描述与字段。
4. 点击「保存」。

**行内操作：**
- **状态快速切换**：直接点击该行「状态」下拉框选新状态，自动保存。
- **编辑**：✏️ 打开弹窗修改。
- **删除**：🗑️（气泡确认后删除）。

### 5.4 看板（`/kanban`）

- 以看板（Kanban）形式按状态分列展示任务，适合敏捷团队拖拽流转。
- 可在看板上直观查看各状态任务分布，并通过拖拽（若实现）或状态下拉更新进度。

### 5.5 项目组合（`/portfolio`）

- 从组合（Portfolio）视角查看多个项目的整体投资、优先级与资源占用，适合高层管理者做组合级决策。

## 第 6 章 计划与进度

### 6.1 OKR 目标（`/okrs`）

- 管理 **目标（Objective）与关键结果（Key Result）**，将项目工作对齐到组织目标。
- 可新建 Objective，并在其下添加多个 KR，跟踪完成度。

### 6.2 日历（`/calendar`）

- 以日历视图展示任务、里程碑、Sprint 等的排期。
- 支持按月 / 周 / 日切换，直观查看资源在时间轴上的分布。

### 6.3 Sprint 管理（`/sprints`）

- 管理迭代（Sprint）：创建 Sprint、设定时间盒、关联任务、跟踪燃尽与完成度。
- 适合 Scrum 团队进行冲刺规划与回顾。

### 6.4 产品路线图（`/roadmap`）

- 以时间轴/泳道形式展示产品与项目的演进路线，便于向干系人汇报方向。

## 第 7 章 监控与评价

### 7.1 报表（`/reports`）

- 生成与导出多种项目报表（系统支持日报 / 周报 / 项目报告等多类报表，可导出）。
- 选择报表类型与项目范围后生成，并可下载分享。

### 7.2 EVM 挣值管理（`/evm`）

- 基于 **挣值管理（EVM）** 方法，计算 PV / EV / AC、进度偏差（SV）、成本偏差（CV）、SPI、CPI 等核心指标。
- 用于量化判断项目是否"进度延误 / 成本超支"。

### 7.3 风险登记册（`/risk`）

- 集中登记项目风险：风险名称、类别、概率、影响、应对措施、责任人。
- 配合 AI WBS 可自动识别并回写风险（见 9.3）。

### 7.4 变更控制（`/changes`）

- 管理变更请求（Change Request）：提交变更、评估影响、走审批流、记录决策。
- 保证项目范围、进度、成本变更受控。

### 7.5 资源管理（`/resources`）

- 管理人力 / 设备等资源及其在项目间的分配，识别资源冲突与过载。

## 第 8 章 审批与合规

### 8.1 审批流（`/approvals`）

- 配置多级审批流程（审批流 + 步骤 + 委托人）。
- 业务对象（如变更请求、预算）可发起审批，按预设步骤流转，支持审批通过 / 驳回 / 转交。
- 系统提供丰富的审批端点（含步骤管理、委托、历史查询）。

### 8.2 合规管理（后台）

- 提供合规策略（CompliancePolicy）、控制项（Control）、审计（Audit）、证据（Evidence）管理能力，满足受监管行业的合规留痕需求。

## 第 9 章 AI 能力

> 系统内置 AI 引擎，默认注入 MiniMax 种子 Key，**首次启动即具备基础 AI 能力**，无需联网配 Key 即可使用 AI WBS、AI 辅助填写等。高级场景可在「设置 → LLM 配置」中更换或新增厂商。

### 9.1 AI 智能体（`/agents`）

- 与单个 AI Agent 对话 / 下发任务，用于问答、文档生成、方案起草等。
- 支持流式响应（逐字输出）。

### 9.2 多智能体编排（`/orchestration`）

- 将多个专职 Agent 编排协作，完成复杂任务（如"先由规划 Agent 出 WBS，再由风险 Agent 评估风险"）。
- 适合需要多角色协同的自动化场景。

### 9.3 AI WBS 生成（`/ai/wbs`）

这是最常用、且已与业务数据打通的 AI 功能：

1. 进入「AI → AI WBS」（或仪表盘快捷操作「AI 智能体」）。
2. 填写生成参数：
   - **项目名称**（必填）：如"通维 AI-PM V1.0 研发"。
   - **项目描述**：如"面向中小企业的项目管理 SaaS，含任务、看板、报表模块，6 人团队 3 个月交付"。
   - **行业类型**：IT软件 / 建筑工程 / 咨询。
   - **保存到项目（可选）**：选择已有项目后，WBS 会回写为真实任务。
   - ☑ **将生成的 WBS 与风险回写为真实任务/风险数据**：勾选后，AI 产出的任务与风险会直接写入数据库。
3. 点击「生成 WBS」。
4. 结果区展示：
   - **WBS 结构表**：WBS 编码、名称、工期(天)、阶段。
   - **识别到的风险表**：风险、类别、概率、影响。
   - 若回写成功，出现绿色提示"已回写 N 个任务到项目"，点击「查看任务」直达任务页验证。

> ✅ 这是 AI 产出与业务数据闭环的关键：AI 不只是"给建议"，而是直接生成可执行的任务与风险。

### 9.4 知识库（RAG）（`/knowledge`）

- 上传文档构建知识库，系统通过 **语义检索 + 检索增强生成（RAG）** 让 AI 基于你的私有资料作答，减少幻觉。
- 适合沉淀规范、模板、历史案例供 AI 引用。

### 9.5 AI 辅助填写（全局）

- 在项目 / 任务等表单中，带有 **AI 图标** 的按钮可一键调用 AI，根据上下文自动补全字段（如项目描述、任务拆解），大幅提升录入效率。

## 第 10 章 自动化与集成

### 10.1 自动化规则（`/automations`）

- 配置"当 X 发生时，执行 Y"的自动化规则（事件触发 + 动作），如"任务逾期时自动通知负责人"。
- 与 Webhook、通知联动实现无人值守流转。

### 10.2 Webhook（`/webhooks`）

- 配置出站 Webhook：当指定事件发生时，向外部 URL 推送 JSON（使用 HMAC-SHA256 签名，支持重试与投递记录），便于对接自有系统或 Zapier/Make。

### 10.3 第三方集成（`/integrations`）

系统支持 7 类平台 OAuth 集成（基于真实 OAuth2）：

| 平台 | 用途 |
|------|------|
| 飞书 | 消息、多维表格同步 |
| 钉钉 | 消息、审批同步 |
| 企业微信 | 消息、通讯录同步 |
| Slack | 消息、频道 |
| GitHub | 仓库、Issue 同步 |
| Google | 日历 / Drive / Sheets |
| Zoom | 会议管理 |

**连接步骤（以飞书为例，其他同理）：**
1. 进入「集成」页，找到目标平台卡片（显示状态标签 `connected` / 未连接）。
2. 点击「连接」。
3. 在弹窗中粘贴外部系统授权后返回的 **授权码（code）**，点击确认。
   > 前提：后端 `.env` 已配置对应 `client_id` / `client_secret`（未配置时系统会诚实报错，不会返回假数据）。
4. 连接成功后卡片状态变为 `connected`，出现「同步」「断开」按钮。
5. 点击「同步」可选择同步类型：默认 / Issues(多维表格) / 日历 / 录制 / 审批，并可指定目标项目 ID。

### 10.4 OpenClaw 集成

**定位**：OpenClaw 是目标机器上已有的运行环境/服务。本系统可在大模型配置变更时，自动把配置同步过去，使其与本系统使用同一套模型。

**两路同步机制：**
- 写入本机文件：`~/.openclaw/system_model.json`
- 推送 HTTP：`http://localhost:18888`

**配置入口（持久化到数据库）：**
1. 进入「设置 → OpenClaw 配置」（系统设置区）。
2. 字段：
   - **启用 OpenClaw 同步**：开关。
   - **OpenClaw 地址**：默认 `http://localhost:18888`。
3. 保存后配置 **持久化到数据库**，重启不丢失（已修复旧版"重启即丢失"的问题）。
4. 点击「同步状态」可查看当前是否与 OpenClaw 模型对齐。

> 即使目标机器未运行 OpenClaw，本系统也能独立运行：同步失败时会静默降级（仅写入本地文件），不阻塞业务。

## 第 12 章 系统配置

### 12.1 设置（`/settings`）

设置页是平台级配置中枢，主要分区：

- **LLM 配置（系统级 / 用户级）**：
  - 系统级：管理员配置全局默认大模型厂商与 Key（**AES-256-GCM 加密存储**）。
  - 用户级：普通用户可绑定自己的 Key 覆盖系统默认。
  - 支持 11 个 Provider：OpenAI、DeepSeek、Anthropic、百度文心、阿里通义千问、腾讯混元、智谱GLM、Moonshot Kimi、硅基流动、MiniMax(默认)、自定义（OpenAI 兼容）。
- **OpenClaw 配置**：见 10.4。
- **用户与角色管理**：
  - 创建/禁用用户、分配角色。
  - 系统内置 **RBAC 细粒度权限（18 种）**，可控制谁能访问审批、集成、系统设置等。
- **安全设置**：密码策略、会话、审计日志查看。
- **API Key 管理**：为开发者生成接口调用密钥。

### 12.2 方法论模板（`/methodology`）

- 管理瀑布 / 敏捷 / 混合等方法论模板，新建项目时可直接套用，保证组织实践一致。

### 12.3 MCP 协议（`/mcp`）

## 第 13 章 常见问题（FAQ）与排错

**Q1：双击 `启动.bat` 没反应 / 闪退？**
- 确认已安装 Python 3.11+ 且加入 PATH（命令行输入 `python --version` 验证）。
- 右键「以管理员身份运行」重试；若被 Windows 拦截，点击"更多信息 → 仍要运行"。
- 查看 `backend/logs/` 下的日志定位报错。

**Q2：浏览器打不开 `http://localhost:8000`？**
- 确认 8000 端口未被其他程序占用（如已装的其他服务）。
- 确认启动脚本已执行完毕（首次依赖安装需 2–5 分钟，请耐心等待）。
- 检查防火墙是否放行 8000 端口。

**Q3：从局域网其他电脑访问空白 / 接口报错？**
- 安装包已使用相对 `/api`（同源 8000），直接用 `http://<本机IP>:8000` 访问即可，无需改配置。
- 若仍不行，检查本机防火墙是否允许 8000 入站。

**Q4：左侧导航栏底部菜单（如"设置"）看不到？**
- 已修复：菜单区现在独立滚动，顶部 Logo 固定；若菜单多，直接滚动左侧栏即可看到全部项。

**Q5：AI 功能不可用 / 提示无 Key？**
- 默认内置 MiniMax 种子 Key，开箱即用；若被清空，请到「设置 → LLM 配置」重新填写厂商与 Key（AES 加密存储）。

**Q6：想换数据库为 PostgreSQL（生产环境）？**
- 编辑 `backend/.env`，将 `DATABASE_URL` 改为 PostgreSQL 连接串，并安装对应驱动（参见 README-安装包.md 的生产环境指引）。

**Q7：目标机器完全无外网，依赖怎么装？**
- 先在能联网的同配置机器上运行 `启动.bat` 生成 `backend/venv`，再把整个 `AI-PM-Installer`（含 venv）一起拷贝到离线机器运行即可。

**Q8：忘记 admin 密码？**
- 停止服务，删除 `backend/` 下的 SQLite 数据库文件（如 `app.db` / `*.db`），重新启动，初始化脚本会重建 admin/admin123。
- 或进入数据库直接重置用户密码字段（需 bcrypt 重新哈希）。

**Q9：OpenClaw 同步失败影响业务吗？**
- 不影响。同步失败会静默降级（仅写本地文件），本系统照常运行。

**Q10：如何更新到新版本？**
- 备份 `backend/` 下的数据库文件与 `.env`，然后用新版安装包覆盖 `backend/`（保留数据库与 .env），重新启动即可。
