# 01 · 项目章程（Project Charter）

> 过程：**4.1 制定项目章程**（启动过程组）。本文件正式授权「通维AI项目管理系统」项目的存在，并记录高层级需求、边界、约束与主要干系人。

---

## 1. 项目目的与立项依据（Business Case）

传统项目管理工具依赖人工拆解 WBS、手动排期与分散沟通，导致进度/成本可见性低、风险滞后。本项目旨在构建**全球顶尖的 AI 驱动型项目管理平台**，以自然语言生成 WBS、多 Agent 协同执行、实时自优化，并集成企业 IM（飞书/企微/钉钉）与研发工具（GitHub），从「人管项目」升级为「AI 执行主体 + 人监督」。

## 2. 高层级项目描述

| 项 | 内容 |
|----|------|
| 项目名称 | 通维AI项目管理系统 (TW-AI PM) |
| 版本目标 | v0.1 — 可部署、可运行的 MVP 全栈平台 |
| 产品形态 | Web SPA（前端）+ REST/WebSocket API（后端）+ 可选 MCP 服务 |
| 核心交付 | 组合/项目/任务全生命周期、AI-WBS、EVM、风险管理、自动化、集成生态 |

## 3. 高层级需求（High-level Requirements）

1. **AI 执行主体**：自然语言→WBS 智能分解；多 Agent 协同；实时自优化。
2. **企业级 PM**：Portfolio 组合管理、EVM 挣值管理、风险管理。
3. **深度集成**：飞书/企微/钉钉/Slack/GitHub/Zoom 等。
4. **RAG 知识库**：文档上传、语义搜索、检索增强生成。
5. **11 家 AI Provider**：OpenAI/DeepSeek/Anthropic/百度/阿里/腾讯/智谱/Moonshot/Qwen/硅基流动/自定义。
6. **开放生态**：MCP 协议、Webhook、Zapier、应用市场。

## 4. 高层级项目边界（Boundary）

- **范围内**：平台自身功能、数据模型、API、AI 引擎、部署包、前端界面。
- **范围外（v0.1）**：部分 REST/数据模型能力（多智能体、知识库、合规、审批、预算、Wiki）暂未提供独立 Web 管理页面，仅以 `/docs` 或 MCP 工具调用。

## 5. 高层级风险（High-level Risks）

| 风险 | 影响 | 初步应对 |
|------|------|----------|
| LLM API Key 未配置 | AI 功能不可用（返回 503） | 文档明确提示，优雅降级 |
| 使用默认弱 SECRET_KEY | 生产环境拒绝启动 | 安全清单强制强随机密钥 |
| 邮件/集成凭证缺失 | 通知失败 | 优雅失败并记录告警，不伪造成功 |

## 6. 里程碑总表（高层级）

| 里程碑 | 说明 |
|--------|------|
| M1 核心数据模型 | 62 张表、Alembic 迁移就绪（系统最终以 `附录-系统技术映射/19` 为准：72 张数据表） |
| M2 AI 能力闭环 | WBS 生成回写 tasks/risks 表 |
| M3 集成与自动化 | Webhook/Zapier/MCP/自动化引擎可用 |
| M4 部署包 | Docker Compose 一键部署 + 生产安全清单 |

## 7. 总体预算与资源（高层级）

- 基础设施：PostgreSQL 15、Redis 7（容器化）。
- 算力：LLM 调用按 Provider 计费（外部采购，见知识领域 11）。
- 人力：后端（FastAPI/AI）、前端（React）、DevOps（Docker）。
