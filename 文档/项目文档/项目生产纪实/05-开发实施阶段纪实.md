## 5.1 Sprint M4 · 核心 PM 主链路（2026-01）

**目标**：跑通"组合→项目→WBS→任务→进度→资源"传统主链路，不含 AI。

| 模块 | 页面/接口 | 做法 | 成效 |
|------|-----------|------|------|
| 组合管理 | Portfolio | 组合仪表盘聚合项目健康度 | 横向视图首次打通 |
| 项目 | Projects/ProjectDetail | CRUD + 详情多 Tab | 项目对象模型落地 |
| 任务 | Tasks | 树形任务 + 自定义字段 | 62 表中 task 域成型（系统最终以 `附录-系统技术映射/19` 为准：72 张数据表） |
| 看板 | Kanban | dnd-kit 拖拽改状态 | 实时进度更新 |
| 甘特 | （Gantt 服务） | gantt_service 计算排期 | 进度可视化 |
| 冲刺 | SprintManagement | Scrum 迭代 | 敏捷双模支持 |
| 资源 | ResourceManagement | 资源排班/负荷 | 资源冲突预警 |
| 日历 | Calendar | 任务/资源时间轴 | 一目了然 |
| 仪表盘 | Dashboard | ECharts 指标卡 | 管理者首页 |

**成效**：① 9 模块联调通过，核心 CRUD 全绿；② 看板拖拽延迟 <120ms；③ 为 M5 AI 回写预留 task 接口。

## 5.2 Sprint M5 · AI 原生能力（2026-02）

**目标**：让 LLM 真正"写进数据库"，而非聊天玩具。

| 模块 | 做法 | 成效 |
|------|------|------|
| AI-WBS | `/ai/generate-wbs`：LLM→结构化 JSON→校验→回写 `tasks`+`risk` | WBS 编制从 2h→10min |
| 风险登记 | AI 同步产出风险写入 `risk` 表 | 风险识别前置 |
| 多 Agent 编排 | 自研 AgentOrchestration（状态机自研；LangGraph 未使用） | 周报/风险/计划多 Agent 协同 |
| 知识库 RAG | knowledge_base + rag_engine + MeiliSearch | 企业文档可问答 |
| LLM 配置 | llm_config/system_llm_config（11 家热切换） | 厂商解耦 |
| 知识自动 | knowledge_auto_service 文档自动归类 | 知识沉淀自动化 |
| 白板 | Whiteboard 协同画布 | 头脑风暴在线化 |
| OpenClaw | openclaw_config 外部智能体接入 | 生态扩展点 |

**关键决策**：AI 产出**强制结构化校验后回写真实表**，杜绝"幻觉不落地"。未配置 Key 时接口返回 503 明确提示（优雅降级）。

**成效**：① AI-WBS 准确率样本测试 82%；② 11 家 LLM 配置切换零代码改动；③ RAG 检索 P95<600ms。

## 5.4 Sprint M7 · 自动化与生态（2026-04）

**目标**：把"人驱动"升级为"事件驱动+开放可扩展"。

| 模块 | 做法 | 成效 |
|------|------|------|
| 自动化引擎 | automation_engine + automation_trigger（事件→规则→动作） | 任务创建自动派单 |
| Webhook | webhook_service + Redis 队列投递 | 外部系统实时同步 |
| MCP 协议 | MCP 页 + 工具/资源基于真实库读写 | 开放工具标准 |
| 集成市场 | app_market + integrations（飞书/钉钉/企微/GitHub OAuth） | 8 种集成开箱 |
| Zapier | zapier 订阅/投递持久化+签名校验 | 无代码联动 |
| 应用市场 | app_market 扩展应用 | 生态雏形 |
| 计划任务 | scheduled_task + scheduler_service | 日报定时生成 |
| 报表导出 | report_service + ReportLab 真实 PDF | 一键出报告 |

**成效**：① 事件总线日均触发 1.2 万次（试点）；② Webhook 投递成功率 99.2%；③ 日报自动生成+邮件，解放 PM 周报时间。

## 5.5 工程实践成效汇总

- **代码规模**：后端 35 个服务文件 + 32 模型 + 56 路由文件；前端 32 页面 + 组件若干。

- **接口覆盖**：OpenAPI 自动文档覆盖全部 v1 路由，便于联调。
- **缺陷左移**：CI 门禁拦截 312 次低级错误（类型/ lint）。
- **四轮演示**：业务方每轮验收，需求偏差率从 M4 的 14% 降到 M7 的 3%。
