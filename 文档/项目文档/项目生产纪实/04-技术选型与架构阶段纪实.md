# 04 · 技术选型与架构阶段纪实（M3 · 2025-12）

> 节点定位：把"蓝图"落到"技术地基"。回答"用什么栈、怎么分层、AI 怎么接、部署怎么搞"。

## 4.1 选型原则

可私有化、可演进、团队熟悉度、AI 友好、成本低。每项选型均做 A/B 对比与 PoC 验证。

## 4.2 关键选型与理由

| 维度 | 候选 | 选定 | 理由（效果） |
|------|------|------|--------------|
| 后端框架 | Django / **FastAPI** | FastAPI | 异步原生、OpenAPI 自动、AI 调用高并发友好 |
| ORM | SQLAlchemy 1.4 / **2.0 Async** | 2.0 Async | 异步会话、类型安全 |
| 前端 | Vue / **React 18+TS** | React+TS | 生态广、AntD 企业级组件全 |
| 构建 | Webpack / **Vite** | Vite | 冷启 <1s，HMR 快 5× |
| 数据库 | MySQL / **PostgreSQL/SQLite** | PG（产）/SQLite（开） | JSONB、向量扩展友好；SQLite 开箱即用 |
| AI 接入 | 单厂商 SDK / **自研 LLM Provider+可插拔（可选 LangChain 集成）** | 插件化 | 支持 OpenAI/Anthropic 等 **11 家** 热切换 |
| 缓存/队列 | Memcached / **Redis** | Redis | 缓存+Celery 队列+Webhook 投递一体 |
| 部署 | 裸机 / **Docker Compose** | Docker | 3 分钟起站，私有化友好 |
| 文档导出 | 手写 / **ReportLab** | ReportLab | 真实 PDF 报表 |

## 4.3 系统架构蓝图

```
[浏览器 SPA] 
   │  /api (VITE_API_BASE)
   ▼
[FastAPI 网关] → 认证/JWT → 路由 v1/*
   ├─ 业务服务 services/（项目/任务/审批/自动化…）
   ├─ AI 服务 services/ai/（自研 Agent/LLM Router/RAG；LangGraph 未使用）
   ├─ 集成 services/integrations/（飞书/钉钉/企微/GitHub）
   ├─ 调度 lifespan：scheduler / queue_worker / recurring
   └─ 数据层：SQLAlchemy → PostgreSQL | SQLite
       缓存/队列：Redis；检索：MeiliSearch；图：Neo4j（可选；注：MeiliSearch / Neo4j 为规划/可选组件，当前未启用，实际全文检索由 PostgreSQL 原生实现）
```

**分层解耦**：表现层(SPA) / 接口层(FastAPI) / 服务层(services) / 数据层(models) 四层，便于测试与替换。

## 4.4 基础框架搭建（M3 产出）

- 后端脚手架：main.py + 路由聚合 + 配置中心 config.py + 日志 logging.py。
- 安全基座：JWT(passlib bcrypt) + SECRET_KEY 弱密钥校验 + AES-256-GCM 字段加密。
- 数据基座：Base/会话/迁移(Alembic) + 初始管理员 init_admin。
- 前端脚手架：Vite + 路由 + 设计令牌 + axios 代理。
- CI 雏形：pytest 用例骨架、ESLint/tsc 门禁。

## 4.5 架构决策记录（ADR 摘要）

- **ADR-01** 异步全栈：选 FastAPI Async，预期并发提升 3×。
- **ADR-02** AI 插件化：避免厂商锁定，llm_config 表驱动。
- **ADR-03** 同源托管：生产镜像后端托管前端静态，简化部署。
- **ADR-04** 事件驱动：自动化/Webhook/Zapier 统一事件总线（Redis 队列）。
