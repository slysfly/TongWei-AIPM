# 03 · 产品设计与方案阶段纪实（M2 · 2025-11）

> 节点定位：把"需求基线"转成"可构建的蓝图"。回答"长什么样、怎么交互、数据怎么存、页面有哪些"。

## 3.1 信息架构（IA）

以 PMI 五大过程组为纵向骨架，以"组合→项目→任务"三级对象为横向层级，构建导航：

```
工作台(Dashboard)
├─ 组合 Portfolio
├─ 项目 Projects → 项目详情(概览/任务/看板/甘特/风险/文档/报表)
├─ 任务 Tasks / 冲刺 Sprint / 待办
├─ 资源 Resource / 日历 Calendar
├─ AI 中心：AI-WBS / Agent编排 / 知识库 / 白板
├─ 治理：审批流 / 变更控制 / 合规 / 经验教训
├─ 度量：OKR / EVM / 报告 Reports
├─ 扩展：自动化 / Webhook / MCP / 集成市场 / 应用市场
└─ 系统：通知 / 设置 / 权限 / 审计
```

**最终落地 32 个页面**（与 frontend/src/pages 一一对应）。

## 3.2 交互与视觉设计（UI/UX）

- 设计系统：基于 Ant Design 5 二次封装「通维设计令牌」（主色/间距/圆角/阴影统一）。
- 高保真原型：32 页全部出 Figma 高保真，含空态、加载、错误三态。
- 关键交互：看板拖拽（dnd-kit）、甘特缩放、AI 流式输出、富文本（Tiptap）。
- 可访问性：对比度达 WCAG AA，支持键盘可达。

## 3.3 数据模型设计

> 注：本节为 M2 设计阶段口径（蓝图 **62 张数据表**）；系统最终实际建表数以 `附录-系统技术映射/19-数据模型全量清单.md` 为准（共 **72 张数据表**）。

> 表清单与 `backend/app/models/` 中 31 个模型文件（部分文件含多表）一致（设计阶段口径为 32 个模型文件 / 62 张表；最终以 `附录-系统技术映射/19` 为准：31 个模型文件 / 72 张表）。

## 3.4 核心流程设计（节选）

- **AI 生成 WBS 流程**：输入目标 → LLM 产出结构化 JSON → 校验父子/WBS 编码 → 回写 `task` 与 `risk` 表 → 前端甘特渲染。
- **审批流**：发起 → 按角色路由 → 并行/串行节点 → 留痕 → 触发自动化。
- **自动化**：事件(任务创建/状态变更) → 规则匹配 → 动作(通知/Webhook/邮件)。

## 3.5 设计评审与冻结

2025-11-28 设计评审会，UI/数据/流程三方通过，输出《PRD v1.0》《数据字典 v1.0》《高保真原型》，作为 M3/M4 构建基准。
