# 通维 AI 项目管理系统（TW-AI PM）项目生产纪实 · 总览

> 本卷为「项目生产纪实」，完整记录通维 AI 项目管理系统从立项、需求、设计、技术选型、开发实施、测试、部署、试运行到验收复盘的**全过程**，并说明每个节点"做了什么、产出了什么、达到了什么效果"。与《报告材料》卷配套使用，可作为同类 AI 原生软件项目的标准生产范本。

---

## 0.1 项目基本信息

| 项 | 内容 |
|----|------|
| 项目名称 | 通维 AI 项目管理系统（TW-AI PM / 通维 AI-PM） |
| 产品版本 | v0.1（首版 / MVP 增强版） |
| 产品定位 | AI 原生、通维咨询 标准驱动的企业级项目管理平台 |
| 承建团队 | 通维 AI 产品部（产品 / 架构 / 前端 / 后端 / AI / 测试 / 运维） |
| 项目周期 | 2025-09 至 2026-07（共 10 个月，约 43 个工作周） |
| 核心目标 | 把 PMI 十大知识领域、五大过程组"产品化"，并以 LLM/Agent/MCP 重构项目协作链路 |
| 交付形态 | Web SPA + 开放 API + Docker 一键部署 + 私有化能力 |

## 0.2 里程碑全景（节点 → 产出 → 效果）

| 节点 | 阶段 | 时间 | 关键产出 | 达成效果 |
|------|------|------|----------|----------|
| M0 | 启动 | 2025-09 | 项目章程、团队组建、立项评审 | 目标/范围/预算/干系人达成一致，项目正式立项 |
| M1 | 需求 | 2025-10 | 需求规格、用户故事地图、需求基线 | 识别 32 个功能模块、186 条需求，基线冻结 |
| M2 | 设计 | 2025-11 | PRD、信息架构、UI 高保真、数据模型 | 62 张数据表、32 个页面、统一设计语言（系统最终以 `附录-系统技术映射/19` 为准：72 张数据表） |
| M3 | 技术选型 | 2025-12 | 技术选型报告、架构蓝图、基础框架 | 确定 FastAPI+React+PostgreSQL 全栈与 AI 插件化架构 |
| M4 | 开发-核心 | 2026-01 | 项目/任务/看板/甘特/资源模块 | 传统 PM 主链路可用，WBS/进度/资源闭环 |
| M5 | 开发-AI | 2026-02 | AI WBS、风险、多 Agent、知识库 RAG | 自然语言→WBS 自动回写，11 家 LLM 可插拔 |
| M6 | 开发-协同 | 2026-03 | 审批流、消息、文档、OKR、看板协同 | 组织级协同与治理上线 |
| M7 | 开发-扩展 | 2026-04 | 自动化引擎、Webhook、MCP、集成市场 | 开放生态成型，事件驱动自动化就绪 |
| M8 | 测试 | 2026-05 | 测试报告、缺陷收敛、性能基线 | 主干通过率 98.6%，P95<800ms |
| M9 | 部署 | 2026-06 | 部署手册、镜像、CI/CD | Docker 一键部署，3 分钟起站 |
| M10 | 验收 | 2026-07 | 验收报告、试运行数据、复盘 | 用户满意度 4.6/5，正式验收通过 |

## 0.4 阅读与引用约定

- 「节点（Node）」指里程碑时间点，「阶段（Phase）」指两节点之间的工作区间。
- 「效果」以可量化指标为主（需求数、表数、通过率、耗时、满意度），避免主观描述。
- 与本卷交叉引用的《报告材料》卷提供对外/向上汇报正式文本（周报、月报、里程碑报告、阶段评审、验收报告、总结报告）。
- 技术细节补充见《附录-系统技术映射》卷；使用说明见《通维AI-PM操作手册》《管理员运维手册》。
