## 4. 后端部署架构

```
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│  Nginx/CDN    │───▶│  Uvicorn      │───▶│  PostgreSQL    │
│  (TLS/Proxy)  │    │  (FastAPI)    │    │  (数据持久)    │
└───────────────┘    └───────┬───────┘    └───────────────┘
                             │
                     ┌───────┴───────┐
                     │   Redis       │
                     │  (缓存/队列)   │
                     └───────────────┘
```

- 开发模式：`serve.py` 单进程服务（含前端 SPA 同源托管）
- 生产模式：多阶段 Dockerfile → `docker compose up`
- 安全：生产强制 `ENVIRONMENT=production` + 强 `SECRET_KEY` + HTTPS (反向代理 TLS)
