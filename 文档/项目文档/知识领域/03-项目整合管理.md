# 03 · 项目整合管理（Project Integration Management）

> 过程（6 个）：4.1 制定章程 | 4.2 制定计划 | 4.3 指导与管理工作 | 4.4 管理知识 | 4.5 监控工作 | 4.6 实施整体变更控制 | 4.7 结束项目或阶段

## 1. 概述

整合管理是统筹各知识领域的枢纽。通维AI项目管理系统本身作为"整合者"，通过**项目管理计划总纲 + 组合/项目/任务层级 + 审批流 + 自动化引擎 + 审计日志**实现全过程统一管理。

## 2. 系统实现

### 2.1 制定项目章程（4.1）

- 系统"项目创建"即为章程制定的数字化体现。
- 模型：`Project` 含 `name`、`description`、`industry_type`、`project_type`、`priority`、`start_date/end_date`、`budget`、`owner_id`。
- API：`POST /projects` → 创建项目即授权管理。
- 首次管理员：`INITIAL_ADMIN_*` 环境变量 → 自动创建首个超级用户（init_admin.py）。

### 2.2 制定项目管理计划（4.2）

- 系统提供 `Project.settings` (JSON) 存储各子计划配置。
- 里程碑 / 阶段门：`Milestone.gate_criteria` (JSON list) + `Milestone.approval_required`。
- 度量：EVM 基线基线（`baseline_start/baseline_end/baseline_budget`）。

### 2.3 指导与管理项目工作（4.3）

- **AI 执行主体**：`POST /ai/generate-wbs` → 自然语言直接生成 WBS（tasks + 层级 + riska）。
- **自动化引擎**：`automation_engine.py` 事件驱动（任务创建/状态变 → 触发规则 → 写通知/发邮件/调 Webhook）。
- **后台调度器**：`scheduler_service` 管理定时任务；`recurring_task_scheduler` 处理重复任务。
- **队列 Worker**：`queue_worker.py` (worker_manager) 异步处理邮件/通知/报表。

### 2.4 管理项目知识（4.4）

- **Wiki 知识库**：`WikiSpace` → `WikiPage` → `WikiPageVersion`（版本历史）+ `WikiComment`。
- **RAG 知识库**：`KnowledgeBase` → `KnowledgeDocument` → `KnowledgeChunk`（语义搜索 + 检索增强生成）。
- **搜索引擎**：`search_engine.py`（Meilisearch）+ `search` API。

### 2.5 监控项目工作（4.5）

- **仪表盘**：`GET /` → 关键指标（EVM、进度、成本、风险）。
- **监控中间件**：`MonitoringMiddleware`（慢查询 ≥500ms 告警）。
- **监控路由**：`/monitoring`（metrics_collector）。
- **健康检查**：`GET /health`。

### 2.6 实施整体变更控制（4.6）

- **审批引擎**：`approval_engine.py` 处理 `ApprovalFlow` → `ApprovalInstance` → `ApprovalStep` → `ApprovalDelegate`。
- **审计日志**：`AuditLog` 记录所有 create/update/delete 操作，含 entity_type、entity_id、changes、ip_address。
- API：`/approvals` 提交/审批变更。

### 2.7 结束项目或阶段（4.7）

- 项目状态 `ProjectStatus.COMPLETED` / `ARCHIVED`。
- 里程碑 `Milestone.status` 标记完成 → `completed_at`。
- 数据传输：导出 `/exports` → 支持 reportlab PDF、openpyxl Excel。

## 3. 关键数据模型

- `Project` — 项目实体；含 `settings` (JSON) 综合配置。
- `Milestone` — 里程碑/阶段门；`gate_criteria` (JSON)。
- `AuditLog` — 全量操作审计。
- `ApprovalFlow / Instance / Step / Delegate` — 变更审批流。
- `AutomationRule` — 自动化规则定义。

## 4. 对应 API

| 路由 | 标签 | 说明 |
|------|------|------|
| /projects/* | 项目管理 | 章程、CRUD、状态变更 |
| /approvals/* | 审批流程 | 变更控制 |
| /automations/* | 自动化规则 | 事件驱动执行 |
| /audit-logs*（含于 /monitoring） | 监控 | 审计追踪 |
| /exports / /imports | 数据导出/导入 | 收尾传输 |
| /wiki/* | Wiki知识库 | 项目知识管理 |
| /knowledge-base/* | 知识库 | RAG 检索增强 |

## 5. 与其他知识领域的接口

- 变更审批 → 影响**范围/进度/成本**基线。
- 审计日志 → 支撑**质量/合规**追溯。
- 知识管理 (Wiki/RAG) → 支撑**干系人**分享与**风险**经验库。
