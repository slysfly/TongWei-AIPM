# 11 · 项目采购管理（Project Procurement Management）

> 过程（3 个）：12.1 规划采购管理 | 12.2 实施采购 | 12.3 控制采购

## 1. 概述

采购管理涵盖从外部供应商获取产品或服务的过程。在本系统中，采购主要体现在 **AI LLM Provider 管理**、**应用市场**、**外部集成生态（OAuth）** 及 **Webhook/Zapier/MCP 服务采购与接入**。

## 2. 系统实现

### 2.1 规划采购管理（12.1）

- **LLM 供应商规划**：系统支持 11 家 AI Provider 的灵活切换与组合，通过 `LLMConfig` 模型管理。
- **集成需求定义**：`Integration` 模型定义各外部服务的接入类型（Feishu/DingTalk/WeChat/Slack/GitHub/Zoom）。
- **应用市场规划**：`AppPlugin` 定义可安装的第三方插件。

### 2.2 实施采购（12.2）

| 采购类型 | 供应商 | 系统接入方式 |
|----------|--------|--------------|
| AI LLM | OpenAI/DeepSeek/Anthropic/百度/阿里/腾讯/智谱/Moonshot/Qwen/硅基流动/自定义 | `LLMConfig` + API Key (`backend/.env`) |
| IM 推送 | 飞书/企微/钉钉/Slack | `Integration` OAuth2/Webhook |
| 代码仓库 | GitHub | `Integration` OAuth2 |
| 视频会议 | Zoom | `Integration` OAuth2 |
| 自动化连接 | Zapier | `ZapierSubscription` + 签名校验 |
| 搜索引擎 | PostgreSQL 全文检索（Meilisearch 规划中·未启用）| 自托管 | 
| 图数据库 | Neo4j（规划中·未启用）| 自托管 |
| 消息队列 | Redis | 自托管或云实例 |

- **LLM 配置 API**：`/llm-configs` — 管理 Provider、模型、API Key、路由权重。
- **集成 OAuth 流程**：`/integrations` — 标准 OAuth 授权码交换；未配置凭证时明确报错。
- **集成数据双向同步（已落地）**：配置真实凭证后，各集成可拉取真实数据并**回写本系统任务表**（`_persist_synced_tasks`）：
  - GitHub：`sync_issues_to_tasks`（Issue→任务）、`sync_pr_status`（PR 状态）
  - 钉钉：`sync_approvals_to_tasks`（审批实例→任务，需 `DINGTALK_APP_KEY/SECRET`）
  - 飞书：`sync_bitable_to_tasks`（多维表格→任务，需 `FEISHU_APP_ID/SECRET`）
  - 企业微信：通讯录/应用消息（`WECOM_CORP_ID/CORP_SECRET/AGENT_ID`）
  - Google：`sync_calendar_to_tasks` / `sync_drive_files`
  - Zoom：`sync_recordings`、`Slack`：消息/频道。未配置真实凭证时一律优雅报错，绝不返回假数据。

### 2.3 控制采购（12.3）

- **LLM 可用性监控**：AI 接口失败 → 优雅降级，返回 503 提示配置。
- **集成状态检查**：OAuth token 有效性验证。
- **Zapier 订阅**：支持签名校验与轮询，数据库持久化投递。
- **应用市场**：`AppInstallation` 记录安装状态与版本。
- **采购审计**：`AuditLog` 记录配置变更。

## 3. 关键数据模型

- `LLMConfig` — AI Provider 配置（API Key、Model、权重）
- `Integration` — 外部集成 OAuth 配置
- `AppPlugin / AppInstallation` — 应用市场插件与安装
- `Webhook / WebhookDelivery` — Webhook 外部回调
- `ZapierSubscription` — Zapier 事件订阅
- `AuditLog` — 采购配置变更审计

## 4. 对应 API

| 路由 | 标签 | 说明 |
|------|------|------|
| /llm-configs | LLM配置 | AI Provider 管理 |
| /integrations | 集成管理 | OAuth 集成配置 |
| /app-market | 应用市场 | 插件市场与安装 |
| /webhooks | Webhook管理 | 外部回调配置 |

## 5. 供应商选择矩阵

| 供应商 | 类型 | 依赖项 | 回退策略 |
|--------|------|--------|----------|
| OpenAI | AI LLM | `OPENAI_API_KEY` | → DeepSeek / 其他 |
| DeepSeek | AI LLM | `DEEPSEEK_API_KEY` | → OpenAI / 其他 |
| Anthropic | AI LLM | `ANTHROPIC_API_KEY` | → OpenAI / 其他 |
| 百度/阿里/腾讯/智谱 | AI LLM (国内) | 对应 API/Secret Key | → 硅基流动 |
| SMTP 邮件 | 通知 | `SMTP_HOST/USER/PASS` | → 优雅失败 |
| IM (飞书/企微/钉钉) | 沟通 | OAuth 凭证 | → 站内通知降级 |

## 6. 外包（云服务）策略

- **推荐外包**：LLM API 调用、SMTP 邮件发送、OAuth 身份认证。
- **自托管（容灾可控）**：PostgreSQL（数据安全）、Redis（低延迟）、PostgreSQL 全文检索（搜索，Meilisearch 规划中·未启用）、Neo4j（图分析·规划中·未启用）。
- **合同管理**：LLM 按 API 调用量计费；项目预算在 `ProjectBudget` 中跟踪外部服务成本。
