# 10 · 项目风险管理（Project Risk Management）

> 过程（7 个）：11.1 规划风险管理 | 11.2 识别风险 | 11.3 实施定性风险分析 | 11.4 实施定量风险分析 | 11.5 规划风险应对 | 11.6 实施风险应对 | 11.7 监督风险

## 1. 概述

风险管理是项目的关键知识领域。系统提供完整的**风险登记册**、**量化的概率×影响评分**、**AI 辅助风险分析**、**风险预警**及 **响应策略追踪**。

## 2. 系统实现

### 2.1 规划风险管理（11.1）

- `RiskCategory` 枚举：TECHNICAL / SCHEDULE / COST / RESOURCE / QUALITY / EXTERNAL / BUSINESS（7 类），覆盖 风分类体系。
- `Project.settings` 中可配置风险阈值（如：风险评分≥0.7 自动告警）。

### 2.2 识别风险（11.2）

- **手动识别**：`POST /risks` 创建风险条目。
- **AI 自动识别**：`POST /ai/generate-wbs` 同时在 `risks` 表生成关联风险（`ai_analysis` JSON 字段存储 AI 分析）。
- **风险类别**：7 种标准分类，支持扩展。

### 2.3 实施定性风险分析（11.3）

- `Risk.probability` (0–1) — 发生概率
- `Risk.impact` (0–1) — 影响程度
- `Risk.risk_score` = probability × impact（自动计算）
- `Risk.status` 反映分析阶段：identified → analyzing → mitigating → occurred → closed

### 2.4 实施定量风险分析（11.4）

- `Risk.response_cost` — 应对成本量化。
- `EVMSnapshot` — 成本风险（CPI<0.8）与进度风险（SPI<0.8）的定量映射。
- AI 分析：`Risk.ai_analysis` (JSON) 存储 AI 对风险影响的高级定量预测。
- **风险预警**：`RiskAlert` 模型可配置触发条件。

### 2.5 规划风险应对（11.5）

- `Risk.response_strategy` — 四大策略：
  - `avoid`（规避）
  - `mitigate`（减轻）
  - `transfer`（转移）
  - `accept`（接受）
- `Risk.response_plan` — 详细应对方案（Text）。
- `Risk.response_cost` — 应对预算。

### 2.6 实施风险应对（11.6）

- 自动化引擎：风险状态变更 → 触发 `AutomationRule` → 创建应对任务/发送通知。
- 风险负责人：`Risk.owner_id` 指派应对负责人。
- 里程碑阶段门：风险遗留项可作为 `Milestone.gate_criteria` 的条件。

### 2.7 监督风险（11.7）

- 风险状态跟踪：`occurred_at`（实际发生时间）、`closed_at`（关闭时间）。
- EVM 联动：成本/进度偏差（CV/SV）同步反映风险影响。
- 定期风险审计：`ComplianceAudit` 可包含风险审查项。

## 3. 关键数据模型

- `Risk` — 风险登记；`probability`、`impact`、`risk_score`、`category`、`response_strategy`
- `RiskAlert` — 风险预警配置
- `Task` — 风险应对任务（EVM 联动指标）
- `EVMSnapshot` — 风险量化数据
- `Milestone` — 风险关闭条件（gate_criteria）

## 4. 对应 API

| 路由 | 说明 |
|------|------|
| /risks (implied) | 风险 CRUD、量化、状态变更 |
| /ai/generate-wbs | AI 同步生成风险条目 |
| /ai/nlp | AI 风险分析查询 |
| /automations | 风险阈值触发的自动化规则 |

## 5. 风险管理流程

```
识别（手动/AI）
    ↓
定性分析（概率 × 影响 = 风险评分）
    ↓
定量分析（AI 预测 + EVM 联动）
    ↓
规划应对（策略 × 计划 × 预算）
    ↓
实施应对（自动化规则 + 任务创建）
    ↓
监督风险（状态跟踪 + 再评估）
```

## 6. 风险分类矩阵

| 类别 | 概率范围 | 影响范围 | 典型应对 |
|------|----------|----------|----------|
| 技术 | 0.1–0.9 | 0.1–1.0 | mitigate（早期原型） |
| 进度 | 0.3–0.7 | 0.3–1.0 | mitigate（缓冲+关键路径） |
| 成本 | 0.2–0.8 | 0.5–1.0 | transfer（固定价合同） |
| 资源 | 0.1–0.5 | 0.3–0.8 | avoid（提前获取） |
| 质量 | 0.1–0.4 | 0.5–0.9 | mitigate（测试加人） |
| 外部 | 0.1–0.3 | 0.3–0.7 | accept（应急储备） |
| 业务 | 0.1–0.3 | 0.5–1.0 | transfer（保险/合同） |
