# 07 · 项目质量管理（Project Quality Management）

> 过程（3 个）：8.1 规划质量管理 | 8.2 管理质量 | 8.3 控制质量

## 1. 概述

质量管理的目标是确保产品满足需求且过程符合标准。系统通过**自动化测试（pytest）**、**合规框架**、**审批门审查**与**报表质量度量**来保障质量。

## 2. 系统实现

### 2.1 规划质量管理（8.1）

- **合规体系**：`CompliancePolicy` → `ComplianceControl`（具体控制项）→ `ComplianceAudit`（审计实例）→ `ComplianceEvidence`（审计证据）。
- **里程碑阶段门**：`Milestone.gate_criteria` 定义质量通过标准（JSON 列表，如「测试覆盖≥80%」「审批通过」）。
- **质量指标定义**：可在 `Project.settings` 或 `CustomField` 中定义项目级质量 KPI。

### 2.2 管理质量（8.2）

- **单元测试**：`backend/tests/` 目录，pytest + 自动使用独立 SQLite 测试库。覆盖：认证、CRUD、MCP、自动化、Webhook、集成、AI 降级。
- **CI 集成**：pytest.ini 配置测试运行参数；GitHub 集成可触发自动化测试。
- **代码审查**：通过审批流 `approval_engine` 可自定义代码合并/发布前的审批步骤。
- **质量管理过程审计**：`ComplianceAudit` 记录质量审计结果。

### 2.3 控制质量（8.3）

- **审批流**：`ApprovalInstance` → `ApprovalStep` → 逐级审批；支持审批委托 `ApprovalDelegate`。
- **审计追踪**：`ComplianceControl` 执行结果记录到 `ComplianceEvidence`。
- **报表质量**：`/reports` 模块支持质量数据报表（缺陷密度、测试通过率等）。
- **数据完整性控制**：数据库级约束（`unique`、`Index`）、模型级 Pydantic 校验（v2）。
- **权限控制**：RBAC 确保只有授权用户可修改质量配置。

## 3. 关键数据模型

- `CompliancePolicy` — 合规政策定义
- `ComplianceControl` — 具体控制项（如：单元测试覆盖、安全扫描、代码审查）
- `ComplianceAudit` — 审计实例（时间、范围、结论）
- `ComplianceEvidence` — 审计证据（截图、报告、日志）
- `Milestone` — 阶段门质量检查 (`gate_criteria`)
- `ApprovalFlow / Instance / Step / Delegate` — 质量审批流

## 4. 对应 API

| 路由 | 标签 | 说明 |
|------|------|------|
| /compliance/* | 合规管理 | 政策、控制、审计、证据 CRUD |
| /approvals/* | 审批流程 | 质量审批 |
| /reports | 报表 | 质量 KPI 报表 |
| /milestones/* | — | 阶段门质量检查 |

## 5. 质量保证（QA）措施

| 措施 | 内容 |
|------|------|
| 单元测试 | pytest 覆盖认证/CRUD/MCP/自动化/Webhook/集成/AI |
| 数据库测试 | 自动使用独立 SQLite 测试库，不影响生产数据 |
| 数据校验 | Pydantic v2 schema 层校验 + SQLAlchemy 2.0 模型约束 |
| 权限校验 | JWT + RBAC (Role/ProjectMember) 中间件拦截 |
| 安全审计 | `security_compliance.py` 安全合规检查 |
| 监控告警 | `MonitoringMiddleware` 慢查询告警（≥500ms） |
| 加密传输 | JWT token + 可选 HTTPS（反向代理终止 TLS） |
| 密码安全 | passlib + bcrypt 密码哈希 |

## 6. 质量度量指标

- 测试通过率：pytest exit code 0 = pass
- API 响应时间：`X-Process-Time` header / 监控中间件采集
- 慢查询比例：≥500ms 请求 / 总请求数
- 审计完成率：`ComplianceAudit` 已完成/已计划
