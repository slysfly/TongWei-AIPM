# 06 · 项目成本管理（Project Cost Management）

> 过程（4 个）：7.1 规划成本管理 | 7.2 估算成本 | 7.3 制定预算 | 7.4 控制成本

## 1. 概述

成本管理确保项目在批准预算内完成。系统提供**预算登记**、**实际成本跟踪**、**EVM 挣值管理（PV/EV/AC → CPI/SPI → EAC/ETC/VAC/TCPI）** 以及 **AI 预测**。

## 2. 系统实现

### 2.1 规划成本管理（7.1）

- `Project.settings` 中配置成本核算规则（EVM / 实报实销 / 固定预算）。
- 成本类型 `ResourceType`：PERSON（人工）、EQUIPMENT（设备）、MATERIAL（材料）、BUDGET（资金）。

### 2.2 估算成本（7.2）

- **从下而上**：`Task.estimated_hours` → 累加至项目。
- **资源成本**：`Resource.cost_rate`（单位成本）× 分配工时 = 成本。
- AI 辅助：AI WBS 生成时可附带成本估算。`Risk.response_cost` 记录应对成本。
- 模型：`CostRecord` 记录明细。

### 2.3 制定预算（7.3）

- `Project.budget` — 当前预算总额
- `Project.baseline_budget` — 成本基线
- `BudgetCategory` — 预算分类（人力/材料/设备/外包等）
- `ProjectBudget` — 多期/多维预算条目
- `RecurringTask` 可关联周期性成本消耗。

### 2.4 控制成本（7.4）

- **EVM 指标体系**（`EVMSnapshot`）：

| 指标 | 全称 | 公式 | 含义 |
|------|------|------|------|
| PV | 计划价值 | — | 截止日计划完成工作的预算 |
| EV | 挣值 | — | 截止日已完成工作的预算 |
| AC | 实际成本 | — | 截止日实际支出 |
| CV | 成本偏差 | EV − AC | 负值=超支 |
| SV | 进度偏差 | EV − PV | 负值=落后 |
| CPI | 成本绩效指数 | EV / AC | `<1`=超支 |
| SPI | 进度绩效指数 | EV / PV | `<1`=落后 |
| EAC | 完工估算 | BAC/CPI 等 | 按趋势估算最终总成本 |
| ETC | 完工尚需估算 | EAC − AC | 还需多少费用 |
| VAC | 完工偏差 | BAC − EAC | 正值=低于预算 |
| TCPI | 完工尚需绩效指数 | (BAC−EV)/(BAC−AC) | 需维持的 CPI 水平 |

- **AI 预测**：`EVMSnapshot.ai_predictions` (JSON) — AI 对成本趋势的预测。
- **实际成本**：`Project.actual_cost` 汇总；`Task.actual_cost` 明细；`CostRecord` 流水。

## 3. 关键数据模型

- `Project` — `budget`、`baseline_budget`、`actual_cost`
- `Task` — `planned_value`(PV)、`earned_value`(EV)、`actual_cost`(AC)
- `EVMSnapshot` — 全量 EVM 指标（10+ 字段）
- `ProjectBudget / BudgetCategory / CostRecord` — 预算与成本明细
- `Resource.cost_rate` — 资源成本率
- `Risk.response_cost` — 风险应对成本

## 4. 对应 API

| 路由 | 标签 | 说明 |
|------|------|------|
| /budgets | 预算管理 | 预算 CRUD、类别、成本记录 |
| /projects (budget/actual_cost) | 项目管理 | 项目级成本字段 |
| /tasks (PV/EV/AC) | 任务管理 | 任务级 EVM 字段 |
| /evm (implied) | — | EVM 快照 API |
| /reports | 报表 | 成本报表与 EVM 图表 |

## 5. 成本趋势与预测

系统通过定期的 `EVMSnapshot`（snapshot_date）记录截面数据，支持：
- 趋势线分析（PV/EV/AC 曲线 → 预测 EAC）。
- AI 驱动的异常检测（ai_predictions）。
- 自动化告警（CPI < 0.8 或 CV 负超阈值）。
