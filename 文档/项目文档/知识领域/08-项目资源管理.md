# 08 · 项目资源管理（Project Resource Management）

> 过程（6 个）：9.1 规划资源管理 | 9.2 估算活动资源 | 9.3 获取资源 | 9.4 建设团队 | 9.5 管理团队 | 9.6 控制资源

## 1. 概述

资源管理覆盖人力资源（人员）与实物资源（设备、材料、资金）的规划、分配与管控。系统通过 **Resource/ResourceAllocation**、**角色权限（Role/ProjectMember）**、**部门/技能标签**实现。

## 2. 系统实现

### 2.1 规划资源管理（9.1）

- `Resource.type`（PERSON / EQUIPMENT / MATERIAL / BUDGET）区分资源类型。
- `Resource.department` 部门归属；`skills` (JSON list) 技能标签。
- `Role` + `ProjectMember` — 角色定义与项目成员分配。
- 权限 RBAC：`permission.py` 定义权限矩阵。

### 2.2 估算活动资源（9.2）

- `Task.estimated_hours` — 活动工时估算。
- `Resource.cost_rate` — 资源单位成本（元/小时），支持成本核算。
- AI WBS 生成时可附带资源需求估算。

### 2.3 获取资源（9.3）

- `ResourceAllocation` — 将 `Resource` 分配到 `Task` + `Project`。
- `allocated_hours` + `allocated_date` 精确到日。
- 项目成员：`ProjectMember` 关联用户与项目，赋予角色。

### 2.4 建设团队（9.4）

- 用户信息：`User` 含 `department`、`position`、`avatar_url`。
- 团队间沟通：`Message`、`Channel`、`ChannelMember` → 站内消息/频道沟通。
- 集成 IM（飞书/企微/钉钉/Slack）：群组创建与消息同步。

### 2.5 管理团队（9.5）

- 资源冲突管理：相同 `Resource` + 日期范围不可超额分配（应用层检查）。
- 团队绩效：集成报表查看成员任务完成率、工时统计。
- 评论协作：`Comment` 支持任务级讨论。

### 2.6 控制资源（9.6）

- 资源分配变更：通过 `AuditLog` 记录分配变更。
- 资源利用率：`ResourceAllocation.allocated_hours` vs `Resource.capacity`（日产能）。
- 自动化引擎：资源超载触发告警通知。

## 3. 关键数据模型

- `User` — 人员基础信息；`department`、`position`、`is_active`
- `Resource` — 资源主数据；`resource_type`、`skills`、`capacity`、`cost_rate`
- `ResourceAllocation` — 资源-任务分配；`allocated_hours`、`allocated_date`
- `Role / ProjectMember` — 角色与项目成员
- `Comment` — 任务评论

## 4. 对应 API

| 路由 | 标签 | 说明 |
|------|------|------|
| /resources | 资源管理（隐含） | 资源 CRUD |
| /members | 项目成员管理 | 成员增删改 |
| /roles | 角色管理 | 角色定义与权限 |
| /tasks (assignee_id) | 任务管理 | 任务负责人分配 |
| /users | 用户管理（隐含） | 用户 CRUD |

## 5. 资源管理规范

| 概念 | 对应 | 系统实现 |
|------|----------|----------|
| 资源分解结构 (RBS) | 资源分类层级 | `Resource.type` + `department` + `skills` 标签 |
| 资源日历 | 可用时间 | `Resource.capacity`（日产能） |
| 资源直方图 | 需求 vs 可用量 | `ResourceAllocation` 按日期汇总 |
| RACI 矩阵 | 职责分配 | `ProjectMember` + `Role` |
| 团队章程 | 团队行为规范 | `Wiki` 可发布团队章程文档 |
