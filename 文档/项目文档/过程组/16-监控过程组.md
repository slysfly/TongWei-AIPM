# 16 · 监控过程组（Monitoring & Controlling Process Group）

> 过程——整合：4.5–4.6 | 范围：5.5–5.6 | 进度：6.6 | 成本：7.4 | 质量：8.3 | 资源：9.6 | 沟通：10.3 | 风险：11.7 | 采购：12.3 | 干系人：13.4
>
> 监控过程组定期测量绩效并与基准比较，实施变更。

---

## 1. 本过程组在系统中的体现

监控过程组是系统 **仪表盘 + EVM 快照 + 合规审计 + 监控中间件 + 健康检查** 的集中体现。

## 2. 各监控过程

### 2.1 监控项目工作（4.5）

| 监控维度 | 系统实现 | 输出 |
|----------|----------|------|
| 项目健康 | 首页仪表盘 (`/`) | 进度/成本/风险概览 |
| API 性能 | `MonitoringMiddleware` (slow_query_threshold=500ms) | `X-Process-Time` header |
| 系统健康 | `GET /health` | status + version + timestamp |
| 性能指标 | `/monitoring` 路由 + `metrics_collector` | 请求量/响应时间/错误率 |
| 审计跟踪 | `AuditLog` → 全量变更记录 | 操作日志查询 |

### 2.2 实施整体变更控制（4.6）

- 变更提出 → `ApprovalFlow` → `ApprovalInstance` → `ApprovalStep`
- 变更记录 → `AuditLog(action="update", entity_type, changes)`
- 基线更新 → 更新 `baseline_*` 字段（基线变更专用）

### 2.3 确认范围（5.5）

- 里程碑验收：`Milestone.gate_criteria` 检查 + `approval_required` 审批
- 任务状态 `in_review` → 评审通过 → `done`

### 2.4 控制范围（5.6）

- 范围基线 vs 实际：`Project.baseline_start/end` vs `start_date/end_date`
- 范围变更通过审批流控制
- 预算联动：范围变更 → 预算重新核算

### 2.5 控制进度（6.6）

| EVM 指标 | 频率 | 触发告警条件 |
|----------|------|-------------|
| SV (进度偏差) | 每日/事件 | SV < -阈值 |
| SPI | 每日/事件 | SPI < 0.8 |
| 关键路径延迟 | 实时 | 影响里程碑 |

- `EVMSnapshot` — 定期截面数据
- 里程碑状态跟踪：`Milestone.status`(pending/completed/delayed)

### 2.6 控制成本（7.4）

| EVM 指标 | 含义 | 告警阈值 |
|----------|------|---------|
| CV (成本偏差) | 负值=超支 | CV < -阈值 |
| CPI | <1=超支 | CPI < 0.8 |
| EAC vs BAC | 偏差分析 | VAC (完工偏差) |

### 2.7 控制质量（8.3）

- 合规审计：`ComplianceAudit` 周期执行
- 审计证据：`ComplianceEvidence` 收集与验证
- 测试报告：pytest 执行结果
- 审批完成率：已审批/未审批比例

### 2.8 控制资源（9.6）

- 资源利用率：`allocated_hours` / `capacity`
- 资源超载告警
- 资源分配变更审计

### 2.9 监督沟通（10.3）

- 通知已读率
- 集成连接有效性检查
- 邮件投递成功率

### 2.10 监督风险（11.7）

- 风险再评估：定期更新 `probability`/`impact`/`risk_score`
- 风险发生追踪：`occurred_at` 记录
- 风险预警：`RiskAlert` 阈值触发通知

### 2.11 控制采购（12.3）

- LLM API 可用性监控（降级检测）
- 集成 OAuth token 有效性
- Zapier 订阅投递状态

### 2.12 监督干系人参与（13.4）

- 用户活跃度
- 审批响应时间
- 通知互动率

## 4. 告警与通知联动

| 监控事件 | 阈值 | 通知渠道 |
|----------|------|----------|
| 进度偏差 | SV < -10% | 站内通知 + 邮件 + IM |
| 成本超支 | CPI < 0.85 | 站内通知 + 邮件 |
| 风险评分过高 | risk_score > 0.7 | 站内通知 + 负责人 |
| 慢查询 | response > 500ms | 日志告警 |
| 集成断开 | OAuth token 过期 | 站内通知 + 邮件 |
