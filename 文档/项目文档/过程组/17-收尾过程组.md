# 17 · 收尾过程组（Closing Process Group）

> 过程（1 个）：4.7 结束项目或阶段
>
> 收尾过程组正式完成项目/阶段，移交交付物。

---

## 1. 本过程组在系统中的体现

收尾在系统中体现在**项目状态关闭**、**里程碑完成**、**数据导出归档**、**经验知识沉淀**等操作。

## 2. 收尾过程（4.7）

### 2.1 阶段收尾

- **Sprint 收尾**：`Sprint` 状态更新为 `completed`，未完成任务滚动到下一 Sprint。
- **Release 发布**：`ReleaseTask` 关联的任务全部完成 → Release 标记发布。
- **里程碑关闭**：`Milestone.status = completed` + `completed_at` 时间戳；`gate_criteria` 逐项核验。

### 2.2 项目收尾

| 收尾活动 | 系统实现 |
|----------|----------|
| 项目状态关闭 | `Project.status = COMPLETED` 或 `ARCHIVED` |
| 最终审计 | 合规审计 (`ComplianceAudit`) 执行收尾检查 |
| 经验教训 | Wiki 创建项目经验总结页面 |
| 知识归档 | RAG 知识库 (`KnowledgeBase`) 保存项目知识 |
| 数据导出 | `/exports` → PDF(reportlab) / Excel(openpyxl) / Word(docx) |
| 资源释放 | `ResourceAllocation` 标记结束，释放资源 |
| 干系人通知 | 通知所有项目成员项目已结束 |
| 最终财务报表 | EVM 最终快照、预算结算、成本记录封存 |

### 2.3 合同/采购收尾

| 活动 | 系统实现 |
|------|----------|
| LLM 调用统计 | 用量记录（可用于结算） |
| 集成连接关闭 | OAuth token 撤销（可选） |
| 外部服务结算 | `CostRecord` 汇总外部服务费用 |

### 2.4 经验教训过程（4.4 管理项目知识 的收尾体现）

- **Wiki**：项目经验、最佳实践、常见问题编写为 Wiki 页面。
- **知识库 (RAG)**：项目文档上传到 `KnowledgeBase`，供后续项目检索参考。
- **任务模板沉淀**：`TaskTemplate` 可将项目中的典型 WBS 保存为模板复用。
- **自动化规则沉淀**：项目中有效的自动化规则可作为组织过程资产。

## 3. 收尾检查清单

| 检查项 | 系统操作 | 状态 |
|--------|----------|------|
| [ ] 所有任务已完成 | `Task.status = done` 或 `cancelled` | 自动检查 |
| [ ] 所有风险已关闭 | `Risk.status = closed` 或已发生的标记 | 自动检查 |
| [ ] 里程碑全部通过 | `Milestone.status = completed` | 自动检查 |
| [ ] 预算已结算 | `Project.actual_cost` 已最终核算 | 手动确认 |
| [ ] 合规审计完成 | `ComplianceAudit.conclusion` 记录 | 手动确认 |
| [ ] 知识已归档 | Wiki/知识库已写入 | 手动确认 |
| [ ] 导出最终报告 | `/exports` PDF/Excel 导出 | 手动触发 |
| [ ] 干系人已通知 | 项目收尾通知已发送 | 自动发送 |

## 4. 收尾产出物

| 交付物 | 系统对应 |
|------------|----------|
| 最终报告 | `/reports` 项目报告（PDF） |
| 经验教训知识库 | Wiki 页面 / RAG 文档 |
| 项目档案 | 导出数据包（JSON/Excel） |
| 项目终止通知 | `Notification` 发送给全部干系人 |
| 绩效评估 | EVM 最终快照 + 审计记录 |

## 5. 归档与数据保留策略

- 已归档项目 (`ARCHIVED`) 数据保留在数据库中，前端默认不显示。
- `is_deleted` 软删除字段保留数据可追溯。
- 审计日志 (`AuditLog`) 保留全部历史操作记录。
- 数据库备份策略：由 PostgreSQL/Docker volume 持久化。

## 6. 持续改进（PDCA 闭环）

收尾不仅是结束，更是新循环的起点：

```
计划 (Plan) → 项目范围/进度/成本/质量……
  ↓
执行 (Do) → AI WBS → 任务执行 → 自动化
  ↓
检查 (Check) → EVM / 监控 / 审计
  ↓
处理 (Act) → 收尾 → 经验教训 → 组织过程资产
  ↓ (下一项目复用)
    再计划……
```
