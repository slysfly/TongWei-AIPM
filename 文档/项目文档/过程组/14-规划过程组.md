# 14 · 规划过程组（Planning Process Group）

> 过程——范围：5.1–5.4 | 进度：6.1–6.5 | 成本：7.1–7.3 | 质量：8.1 | 资源：9.1–9.2 | 沟通：10.1 | 风险：11.1–11.5 | 采购：12.1 | 干系人：13.2
>
> 规划过程组是**项目中最关键的过程组**，系统提供了强大的 AI 辅助规划能力。

---

## 1. 本过程组在系统中的体现

系统将所有规划活动集中到 **项目创建 → AI WBS → 任务分解 → 资源分配 → 预算制定 → 风险识别** 这一连贯流程中。

## 2. 各规划过程

### 2.1 范围规划（5.1–5.4）

| 过程 | 系统实现 |
|----------|----------|
| 5.1 规划范围管理 | `Project.settings` → 范围管理配置 |
| 5.2 收集需求 | `CustomField` / `FormTemplate` / `Wiki` |
| 5.3 定义范围 | `Project(name/desc)` + `Epic` |
| 5.4 创建 WBS | **AI 核心**：`POST /ai/generate-wbs` → 自然语言 → `tasks`(wbs_code/level/parent) |

### 2.2 进度规划（6.1–6.5）

| 过程 | 系统实现 |
|----------|----------|
| 6.1 规划进度管理 | `ProjectType`(agile/waterfall/hybrid) |
| 6.2 定义活动 | `Task`、`RecurringTask`、`ScheduledJob` |
| 6.3 排列活动顺序 | `TaskDependency`(FS/FF/SS/SF) + `lag_time` |
| 6.4 估算活动持续时间 | `Task.estimated_hours` (AI 辅助估算) |
| 6.5 制定进度计划 | 甘特图服务、里程碑、Sprint 排期 |

### 2.3 成本规划（7.1–7.3）

| 过程 | 系统实现 |
|----------|----------|
| 7.1 规划成本管理 | `Project.settings` 成本规则 |
| 7.2 估算成本 | `Resource.cost_rate` × 工时 → 成本估算 |
| 7.3 制定预算 | `Project.budget` + `ProjectBudget`(分项) |

### 2.4 质量规划（8.1）

- `CompliancePolicy` 定义质量政策
- `ComplianceControl` 定义具体质量控制项
- `Milestone.gate_criteria` 定义阶段门质量验收标准
- `TaskTemplate` 复用质量达标的工作包

### 2.5 资源规划（9.1–9.2）

- `Resource` 资源登记（人员/设备/材料/资金）
- `Role` + `ProjectMember` 角色与成员规划
- `ResourceAllocation` 资源分配方案

### 2.6 沟通规划（10.1）

- `Notification` 通知规则配置
- `Integration` 外部沟通渠道配置
- 用户通知偏好设置

### 2.7 风险规划（11.1–11.5）

- `RiskCategory` 风险分类体系（7 类）
- AI 自动风险识别（WBS 同步生成）
- 概率×影响量化评分
- 四类响应策略（avoid/mitigate/transfer/accept）

### 2.8 采购规划（12.1）

- `LLMConfig` AI 供应商配置
- `Integration` 外部服务 OAuth 凭证
- `Webhook` 外部回调端点配置

### 2.9 干系人参与规划（13.2）

- `Role` 权限定义
- 审批委托配置 (`ApprovalDelegate`)
- 通知偏好设置

## 3. 核心规划路径（推荐使用流程）

```
1. POST /projects → 定义范围（章程）
2. POST /ai/generate-wbs → AI 一键生成 WBS + 活动 + 风险
3. 人工修订 WBS（tasks）
4. 设置依赖关系（task_dependencies）
5. 分配资源（resource_allocations）
6. 确认预算（budget）
7. 设置里程碑（milestones）
8. 配置自动化规则（automations）
9. 通知干系人（notifications）
```

## 4. 规划过程产出的基准

| 基准 | 对应系统字段 | 首次设定时机 |
|------|-------------|-------------|
| 范围基准 | `Project.{description,settings}` + `Task.wbs_code` | 项目创建 + WBS 完成后 |
| 进度基准 | `Project.baseline_start/end` + `Task.planned_start/end` | WBS + 排期完成后 |
| 成本基准 | `Project.baseline_budget` | 预算审批通过后 |
