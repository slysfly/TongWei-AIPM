## 1. 执行摘要

**通维AI项目管理系统（TW-AI PM）** 是新一代 **AI 驱动型项目管理平台**。与传统「人操作工具」范式不同，通维 AI-PM 以 **AI 为执行主体**：用户用自然语言描述目标，AI 自动拆解 WBS、分配任务、识别风险、生成报告，人只做监督与关键决策。

产品深度遵循 **PMI 通维咨询® Guide 第六版**，覆盖 **10 大知识领域 × 5 大过程组**，并支持 **本地私有化部署**，满足金融、政企对数据安全的严苛要求。

### 关键数字

- **10 大知识领域 / 5 大过程组** 全流程覆盖
- **11 家** LLM 大模型可切换（OpenAI / DeepSeek / Anthropic / 百度文心 / 阿里通义千问 / 腾讯混元 / 智谱GLM / Moonshot Kimi / 硅基流动 / MiniMax(默认) / 自定义（OpenAI 兼容））
- **6 大 OAuth** 集成平台（飞书 / 企业微信 / 钉钉 / Slack / GitHub / Zoom）+ Zapier（Webhook）/ MCP
- **72 张** 数据表、**56 个** 路由模块、**~400 个** API 端点
- **30 分钟** Docker Compose 一键上线

## 2. 行业痛点

| 痛点 | 传统工具表现 | 通维 AI-PM 应对 |
|------|-------------|----------------|
| WBS 拆解靠经验 | 项目经理手工拆分，耗时且易漏 | AI 自然语言→WBS，回写任务与风险 |
| 进度/成本不可视 | Excel 手工算 EVM，滞后 | EVM 一键计算 CPI/SPI/EAC |
| 风险滞后发现 | 风险靠例会口述 | AI 风险识别 + 评分预警 |
| 报告占用大量时间 | 周报/月报人工汇总 | AI 自动生成日报/周报 |
| 数据不敢上云 | SaaS 合规风险 | 完全私有化 + RBAC + 审计 |
| 工具孤岛 | IM/代码库割裂 | 6 大 OAuth 平台集成 + Zapier（Webhook）/ MCP 开放 |

## 3. 产品理念：AI 执行主体

```
传统：  人 → 操作工具 → 管理项目   （人=瓶颈）
通维：  人 → 描述目标 → AI 执行 → 人监督决策  （AI 承担 80% 执行）
```

三层 AI 能力：
1. **AI WBS**：自然语言生成工作分解结构，自动回写 `tasks` 与 `risks`。
2. **多智能体编排（Multi-Agent）**：规划/执行/审查 Agent 协同，处理复杂项目流。
3. **RAG 知识库**：上传组织过程资产，语义检索 + 检索增强生成，让 AI 基于企业自身知识作答。

## 4. 技术架构

```
浏览器 ──HTTPS──> [FastAPI :8000]
                   ├── API (/api/v1/*)   56 路由模块 / ~400 端点
                   ├── 前端 SPA (React 18 + TS + Antd)
                   ├── 数据库 PostgreSQL / SQLite (72 表)
                   ├── Redis 缓存/队列/调度
                   └── AI 层：自研 LLM Router/Provider（可选 LangChain 集成；LangGraph 未使用）+ 11 LLM
```

- **后端**：Python 3.11 + FastAPI + SQLAlchemy 2.0（异步）+ Pydantic v2
- **前端**：React 18 + TypeScript + Vite + Ant Design 5 + React Context 状态管理（React Query 规划中）+ @dnd-kit 拖拽 + tiptap 富文本
- **安全**：JWT(HS256) + bcrypt + RBAC + AES-256-GCM 字段加密
- **部署**：Docker Compose（PG+Redis+后端）/ 源码 / 多阶段 Dockerfile

## 6. 部署与安全

- **部署形态**：本地私有化（推荐）、Docker Compose 一键、内网离线。
- **数据安全**：核心数据不出内网；LLM 调用可走私有模型或指定厂商。
- **权限**：RBAC 角色与权限点；操作审计；合规审计（`ComplianceAudit`）。
- **加密**：敏感字段 AES-256-GCM；`SECRET_KEY` 强制强随机（生产弱密钥拒绝启动）。
- **高可用**：PostgreSQL 连接池（20+10）、Redis 缓存、后台 Worker/调度独立进程、进程退出自动重启。

## 7. 商业价值

- **提效**：WBS/报告自动化，项目经理从执行中解放，聚焦决策。
- **可控**：EVM 与风险预警让延期/超支提前暴露。
- **合规**：私有化 + 审计满足等保/信创要求。
- **开放**：MCP/Webhook/应用市场构建生态，保护既有 IT 投资。
