# 通维 AI-PM · 版本发布说明

> 当前版本：**v0.1** ｜ 发布日期：2026-07 ｜ 读者：全员 / 客户 / 实施

---

## 1. v0.1 概述

首个可部署、可运行的 MVP 全栈平台。覆盖项目管理全生命周期、AI 执行主体能力、企业级集成与私有化部署。

## 2. 新特性（v0.1）

### 核心管理
- 组合（Portfolio）、项目、任务、Epic 全生命周期管理
- 看板拖拽、日历、Sprint、路线图、OKR
- 文档、白板、通知、经验教训

### 成本与价值
- **EVM 挣值管理**：PV/EV/AC → CPI/SPI/EAC/VAC/TCPI，红黄绿状态
- 预算与实际成本录入

### 风险
- 风险登记册：7 分类、概率×影响评分、AI 分析、阈值预警、四策略应对

### AI 执行主体
- **AI-WBS**：自然语言→WBS，回写 tasks/risks
- 多智能体编排（规划/执行/审查）
- 知识库 RAG（上传/语义检索/问答）
- AI 辅助填写；11 家 LLM 可切换；系统默认 MiniMax M2.7

### 自动化与集成
- 自动化引擎（事件→规则→动作）
- Webhook、Zapier（签名校验）
- 6 平台 OAuth：飞书/企微/钉钉/Slack/GitHub/Zoom（另 Zapier Webhook / MCP）
- MCP 工具/资源暴露

### 质量与治理
- 审批流、合规管理、变更控制

### 部署与安全
- Docker Compose 一键部署（PG+Redis+后端）
- 一键启动脚本（Windows .bat/.ps1），SQLite 零配置
- JWT+bcrypt+RBAC；AES-256-GCM 字段加密
- 生产弱密钥拒绝启动；结构化滚动日志；监控/健康 API

## 4. 升级指引

- **源码**：拉新代码 → `pip install -r requirements.txt` → `alembic upgrade head` → 重启。
- **Docker**：`docker compose pull && docker compose up -d --build`（迁移自动执行）。
- **升级前**：务必备份数据库（`backend/*.db` 或 PG dump）与 `uploads/`、`.env`（见 `项目文档/通维AI-PM管理员运维手册.md` 第 6 章）。

## 5. 兼容性

- 浏览器：Chrome / Edge / Firefox 最新版。
- 数据库：SQLite（开发）、PostgreSQL 15（生产）。
- 运行环境：Python 3.11+、Node 20（构建）、Docker 20.10+。
