# 通维 AI-PM · 功能规格说明书

> 版本 v0.1 ｜ 读者：研发 / 实施 / 售前
> 逐模块说明字段、交互与业务规则。页面路径以 `frontend/src/pages` 为准。

---

## 1. 认证与账户（Login / Settings）

- **登录**：用户名 + 密码 → JWT（access 30min / refresh 7d）。
- **改密**：需满足策略（长度 ≥12、90 天有效期、弱密码检测）。
- **RBAC**：角色 + 权限点；超级用户 `is_superuser=true`。
- **设置页**：当前用户、LLM 配置（13 厂商）、用户/角色管理、方法论模板、MCP。

## 2. 组合与项目

### 2.1 组合（Portfolio）
- 组合 = 项目集合；支持组合级仪表盘与多维透视。
- 字段：名称、目标、关联项目列表、负责人。

### 2.2 项目（Projects / ProjectDetail）
- CRUD；状态：规划中 / 进行中 / 已暂停 / 已关闭。
- 字段：名称、描述、起止日期、负责人、成员、标签、自定义字段、预算基线。
- 详情页聚合：任务、风险、EVM、文档、白板、经验教训。

### 2.3 任务（Tasks）
- CRUD；状态：待办 / 进行中 / 评审中 / 已完成 / 已阻塞。
- 字段：标题、描述、负责人、优先级、开始/截止、依赖、工时、进度%、关联项目。
- 看板（Kanban）：按状态列拖拽流转。

### 2.4 Epic / 范围
- Epic 拆分至 Story/Task；范围基线可锁定。

## 3. 计划与进度

| 模块 | 关键能力 |
|------|----------|
| OKR | 目标/关键结果对齐，进度追踪 |
| 日历 | 任务/里程碑按日期视图 |
| Sprint（SprintManagement） | 迭代规划、燃尽图 |
| 路线图（ProductRoadmap） | 版本/里程碑时间线 |
| 甘特 | 依赖关系与关键路径（进度知识领域） |

## 4. 成本与挣值（EVM）

- 输入：PV（计划值）、EV（挣值）、AC（实际成本）。
- 输出指标：
  - CPI = EV/AC；SPI = EV/PV
  - EAC = BAC/CPI（或 AC + (BAC−EV)/CPI）
  - VAC = BAC − EAC；TCPI = (BAC−EV)/(BAC−AC)
- 状态：红（CPI<0.8）/ 黄 / 绿；支持 EVM 快照保存（`EVMSnapshot`）。

## 5. 风险（RiskRegister）

- 7 类：技术/进度/成本/资源/质量/外部/业务。
- 量化：`probability`(0–1) × `impact`(0–1) = `risk_score`。
- 状态：identified → analyzing → mitigating → occurred → closed。
- 应对四策略：avoid / mitigate / transfer / accept。
- AI：WBS 生成时同步产出风险条目，`ai_analysis` 存 JSON。
- 预警：`RiskAlert` 阈值触发通知/自动化。

## 6. AI 能力

### 6.1 AI WBS（AIWBS）
- 输入自然语言目标 + 约束（工期/人数/技术栈）。
- 输出分层 WBS，可一键回写 `tasks` 与 `risks`。

### 6.2 多智能体编排（AgentOrchestration / AgentPanel）
- 规划/执行/审查 Agent 协同；可视化编排与执行轨迹。

### 6.3 知识库 RAG（KnowledgeBase）
- 文档上传（pdf/doc/docx/xls/png/jpg/txt/md）；向量化；语义检索；RAG 问答。

### 6.4 AI 辅助填写
- 表单/报告基于上下文自动补全建议。

### 6.5 模型配置
- 11 家 Provider + 系统默认 MiniMax M2.7（首次启动种子写入 `SystemLLMConfig`）。

## 7. 自动化与集成

| 模块 | 规格 |
|------|------|
| 自动化（Automations） | 事件触发规则 → 动作（通知/邮件/Webhook/建任务） |
| Webhook | 事件回调；签名校验 |
| 集成（Integrations） | 飞书/企微/钉钉/Slack/GitHub/Zoom OAuth 连接；消息同步 |
| Zapier | `ZAPIER_WEBHOOK_SECRET` 校验签名 |
| MCP | 工具/资源对外暴露（create_project/create_task 等） |
| 应用市场（AppMarket） | 扩展能力接入 |

## 8. 质量、合规与变更

- 审批流（ApprovalFlow）：多级审批步骤，时间戳留痕。
- 合规管理（Compliance）：控制项、证据、审计（`ComplianceAudit`）。
- 变更控制（ChangeControl）：变更请求→评审→基线更新。

## 9. 协作与文档

- 文档（Documents）：在线协作文档。
- 白板（Whiteboard）：可视化脑暴。
- 通知（Notifications）：站内 + 外部集成推送。
- 经验教训（LessonsLearned）：项目复盘沉淀（收尾过程组）。

## 10. 监控与系统

- 监控 API：`/monitoring/health`、`/metrics`、`/slow-queries`、`/errors`。
- 健康探活：`/health`。
- 日志：`backend/logs/app.log`、`error.log`（滚动 10MB×10）。

## 11. 通用交互约定

- 列表：分页（默认 20 / 最大 100）、筛选、排序。
- 表单：必填校验、错误内联提示。
- 操作：关键写操作需确认；删除软删或硬删依模型。
- 响应式：桌面优先，适配主流浏览器。
