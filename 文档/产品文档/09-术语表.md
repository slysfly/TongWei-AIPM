# 通维 AI-PM · 术语表

> 版本 v0.1 ｜ PMI 术语与产品术语对照，便于跨团队对齐。

---

## 1. PMI / 通维咨询 术语

| 术语 | 英文 | 释义 | 系统落点 |
|------|------|------|---------|
| 项目章程 | Project Charter | 正式授权项目的文件 | `01-项目章程.md` |
| 项目管理计划 | Project Management Plan | 整合各子计划的总纲 | `02-项目管理计划.md` |
| 工作分解结构 | WBS | 可交付成果的分层分解 | AI-WBS 模块 |
| 挣值管理 | EVM | 用货币/工时度量进度与成本 | EVM 模块 |
| 计划值 | PV | 计划完成工作的预算 | EVM 输入 |
| 挣值 | EV | 实际完成工作的预算 | EVM 输入 |
| 实际成本 | AC | 实际发生成本 | EVM 输入 |
| 成本绩效指数 | CPI | EV/AC，<1 超支 | EVM 输出 |
| 进度绩效指数 | SPI | EV/PV，<1 落后 | EVM 输出 |
| 完工估算 | EAC | 预计总成本 | EVM 输出 |
| 完工偏差 | VAC | BAC−EAC | EVM 输出 |
| 完工尚需绩效 | TCPI | 后续所需效率 | EVM 输出 |
| 风险登记册 | Risk Register | 风险清单与状态 | 风险模块 |
| 定性分析 | Qualitative | 概率×影响评分 | 风险评分 |
| 定量分析 | Quantitative | 数值化影响 | EVM/AI 联动 |
| 知识领域 | Knowledge Area | 通维咨询 10 大领域 | 知识领域文档 |
| 过程组 | Process Group | 启动/规划/执行/监控/收尾 | 过程组文档 |
| 干系人 | Stakeholder | 受影响或影响项目的各方 | 用户/RBAC |
| RBAC | 基于角色的访问控制 | 角色权限模型 | 设置/角色 |

## 2. 产品技术术语

| 术语 | 释义 |
|------|------|
| TW-AI PM | 通维AI项目管理系统简称 |
| AI-WBS | 自然语言生成工作分解结构并回写任务/风险 |
| 多智能体 | 规划/执行/审查 Agent 协同编排 |
| RAG | 检索增强生成，基于自有知识库作答 |
| MCP | 模型上下文协议，对外暴露工具/资源 |
| 组合 Portfolio | 项目集合，组合级治理 |
| Epic | 大型工作项，向下拆 Story/Task |
| 看板 Kanban | 按状态列拖拽的任务视图 |
| Sprint | 敏捷迭代（通常 2–4 周） |
| 自动化规则 | 事件→条件→动作 的触发器 |
| Webhook | 事件回调到外部 URL |
| 字段加密 | AES-256-GCM 对敏感字段加密 |
| SECRET_KEY | 签发 JWT 与派生加密密钥的系统密钥 |
| FIELD_ENCRYPTION_KEY | 独立的字段加密密钥（可选） |
| Alembic | 数据库 schema 迁移工具 |
| 监控 API | /monitoring/health、/metrics 等 |
| 系统默认大模型 | 首次启动写入的 MiniMax M2.7 种子配置 |
