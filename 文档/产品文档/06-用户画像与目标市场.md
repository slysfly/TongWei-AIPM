## 1. 目标市场

| 细分 | 规模特征 | 采购驱动力 |
|------|---------|-----------|
| 金融/类金融 | 强合规、数据安全 | 私有化、审计、等保 |
| 政府/国企 | 信创、国产化 | 本地部署、合规 |
| 系统集成商 | 多项目并行 | 组合管理、资源调度 |
| IT/软件外包 | 进度/成本敏感 | AI 报告、EVM、风险 |
| 研发团队 | 敏捷落地 | Sprint、AI-WBS |
| AI 企业 | 前沿模型 | 私有模型接入、11 厂商 |
| 甲方 PMO | 统一视图 | 组合仪表盘、汇报自动化 |

## 2. 用户画像（Persona）

### P1 · 张总 — 企业 CTO / 信息化负责人
- **背景**：国企信息化部门，负责 PM 系统选型。
- **痛点**：数据不能出内网；要等保与审计；团队不愿学复杂工具。
- **诉求**：私有化一键部署、RBAC+审计、上手快。
- **触达**：白皮书 + 等保合规话术 + Demo。

### P2 · 李经理 — IT 公司项目经理（PM）
- **背景**：管 5–8 个并行项目，常加班写周报。
- **痛点**：WBS 拆分耗时；进度靠群里问；风险会后才知道。
- **诉求**：AI 自动出 WBS 与周报；EVM 一眼看健康；风险预警。
- **触达**：短视频「AI 替你写周报」、免费试用。

### P3 · 王工 — 研发 Leader
- **背景**：敏捷团队，Sprint 规划凭感觉。
- **痛点**：燃尽图手工；需求变更频繁。
- **诉求**：AI 辅助 Sprint 规划；与 GitHub 打通。
- **触达**：技术社区、GitHub 集成演示。

### P4 · 赵审计 — 合规/审计员
- **背景**：定期检查项目合规。
- **痛点**：证据分散；过程不可追溯。
- **诉求**：审批流留痕、合规证据集中、审计导出。
- **触达**：合规管理模块演示 + 审计报告样例。

### P5 · 陈管理员 — 企业 IT 运维
- **背景**：负责部署与运维。
- **痛点**：安装复杂；备份困难；监控缺失。
- **诉求**：一键启动、备份脚本、监控 API、HTTPS 指引。
- **触达**：`管理员运维手册` + Docker Compose。

## 4. 市场进入建议

1. **标杆行业**：先打金融/政企（合规刚需）→ 形成案例。
2. **渠道**：系统集成商/代理商分销（见 `营销文案/营销素材包.md` 招商文案）。
3. **试用**：提供 Docker 一键试用镜像，30 分钟体验。
4. **内容**：白皮书 + 短视频 + 客户案例三件套持续投放。
