> 本文定义产品功能需求、用户故事与验收标准，是研发排期与测试的依据。

## 1. 产品目标

| 目标 | 度量 |
|------|------|
| G1 AI 降低执行负担 | AI-WBS 生成可用率 >99%；周报生成 <30s |
| G2 全生命周期可视 | EVM 指标实时计算；仪表盘覆盖组合/项目/任务 |
| G3 安全合规 | 私有化部署；RBAC 覆盖全部写操作；审计可追溯 |
| G4 开放集成 | 6 大 OAuth 平台 + Zapier（Webhook）/ MCP 可用 |
| G5 易部署 | Docker Compose 一条命令上线 |

## 4. 典型用户故事与验收标准

### US-01 AI 生成 WBS
- **作为** 项目经理，**我想** 用一句话描述项目目标，**以便** AI 自动生成可执行的 WBS。
- **验收**：输入「开发一款电商小程序，2 个月上线」，系统返回分层任务并写入 `tasks`；对识别到的关键风险写入 `risks`；可一键采纳/编辑。

### US-02 EVM 实时计算
- **作为** PMO，**我想** 查看项目挣值指标，**以便** 判断成本/进度健康度。
- **验收**：在 EVM 页输入 PV/EV/AC，系统计算 CPI/SPI/EAC/VAC/TCPI 并给出红黄绿状态；支持快照保存。

### US-03 风险预警
- **作为** 风险负责人，**我想** 风险评分超阈值时收到提醒，**以便** 提前应对。
- **验收**：设置阈值 0.7；新建风险评分≥0.7 时自动触发通知并可选创建应对任务。

### US-04 私有化部署
- **作为** 企业 IT，**我想** 在内网一键部署，**以便** 数据不出域。
- **验收**：`docker compose up -d --build` 后服务在 `:8000` 可用；未配置外发 SMTP/AI 时优雅降级。

### US-05 集成同步
- **作为** 团队成员，**我想** 在飞书收到任务指派，**以便** 不切换系统。
- **验收**：配置飞书 App 后，任务创建事件推送飞书消息；点击可跳回系统。

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | API P95 <500ms（常规）；首页加载 <2s |
| 安全 | bcrypt 密码、JWT 30min、RBAC、字段加密、生产强密钥 |
| 可靠 | 后台 Worker/调度独立；进程退出自动重启 |
| 兼容 | 现代浏览器（Chrome/Edge/Firefox）；信创环境可适配 |
| 可维护 | Alembic 迁移；结构化日志；监控 API |
| 合规 | 操作审计；等保三级可支撑（配合网络隔离） |

## 6. 范围与边界（v0.1）

- **范围内**：上述 FR-01~FR-15 对应 Web 页面与 API。
- **部分提供**：多智能体、知识库、合规、审批、预算、Wiki 已有 REST/数据模型，独立 Web 管理页在后续版本补全（当前经 `/docs` 或 MCP 调用）。
- **范围外**：原生移动 App、计费收银、HR 系统。
