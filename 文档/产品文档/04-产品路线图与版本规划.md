# 通维 AI-PM · 产品路线图与版本规划

> 版本 v0.1 ｜ 读者：产品 / 管理层 / 客户
> 说明版本节奏与能力演进方向（规划内容可能随市场需求调整）。

---

## 1. 版本哲学

- **AI 执行主体** 是长期主线：每一版都增强 AI 在「规划—执行—监控—收尾」中的自主度。
- **私有化优先**：数据安全与信创适配贯穿所有版本。
- **标准契合**：持续对齐 PMI 通维咨询 与国标项目管理实践。

## 2. 能力演进时间线

```
v0.1 (当前) ──► v0.2 ──► v0.3 ──► v1.0
 基础闭环       智能增强     生态开放     企业规模
```

### v0.1 — 基础闭环（已发布）
- 组合/项目/任务全生命周期
- AI-WBS、EVM、风险登记册
- 6 平台 OAuth 集成、自动化、Webhook、Zapier、MCP（部分 Web 管理页经 API/MCP）
- 私有化一键部署、RBAC、字段加密

### v0.2 — 智能增强（规划）
- 多智能体编排可视化增强（规划/执行/审查闭环）
- AI 日报/周报/月报自动排程与分发
- 风险预测模型升级（结合历史 EVM 偏差）
- 知识库 RAG 多租户与权限细化
- 独立 Web 管理页补全：合规、审批、预算、Wiki

### v0.3 — 生态开放（规划）
- 应用市场丰富（更多开箱集成）
- MCP 工具市场与第三方 Agent 接入
- 开放 API 配额与计量
- 低代码自动化编排器

### v1.0 — 企业规模（规划）
- 多组织/多租户 SaaS 与私有化并存
- 信创全栈适配（国产数据库/操作系统）
- 等保三级合规套件
- 移动端 App（iOS/Android/鸿蒙）
- BI 自助分析与组织级效能度量

## 3. 重点能力路线图（按领域）

| 领域 | v0.2 | v0.3 | v1.0 |
|------|------|------|------|
| AI | 多Agent闭环、自动报告 | Agent市场 | 自适应自优化 |
| 成本 | 预算基线联动EVM | 多维成本归集 | 组织级效能BI |
| 风险 | 预测模型 | 跨项目组合风险 | 组合风险驾驶舱 |
| 集成 | 更多开箱集成 | 第三方Agent | 生态开放平台 |
| 部署 | 离线镜像 | 信创适配 | 多租户SaaS |
| 合规 | 独立合规页 | 审计自动化 | 等保套件 |

## 4. 版本节奏

- 小版本（patch）：缺陷修复与安全更新，按需发布。
- 中版本（minor）：能力增强，约每季度一次。
- 大版本（major）：架构/范式升级，年度评估。

## 5. 需求来源与优先级

- 客户反馈（售前/实施收集）→ 产品 backlog。
- 标准演进（通维咨询 第七版、国标）→ 规划纳入。
- 技术债与安全 → 始终 P0。
